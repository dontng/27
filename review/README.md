# 闭卷复习入口

**先回答，再打开核对。**不必逐题写长文，先说出关系；分析题还要另练实际书写。下列均为原创提取题，没有用户完成记录。

## 历史唯物主义

同一座工厂的机器、设备所有权、工资分配、相关法律，分别从哪些角度分析？经济基础为什么不是设备总和？

<details>
<summary>核对并回到教学</summary>

机器作为劳动资料进入生产力；设备所有权与工资分配等进入生产关系；相关法律从政治法律上层建筑视角分析。经济基础是一定社会中占统治地位的生产关系的总和，社会层面不能缩为一家工厂的关系。回看[历史唯物主义](../src/mayuan/history-to-capital.md)。

</details>

## 政经

单位商品价值量由什么决定？同一时间产量增加，为什么不能直接判价值总量增加？工资买的是劳动还是劳动力？

<details>
<summary>核对并回到教学</summary>

社会必要劳动时间决定单位商品价值量；产量与新价值不同，要核社会或个别生产率及劳动时间、强度、复杂程度等条件。购买的是劳动力，劳动是其使用；新价值包括补偿劳动力价值和剩余价值。回看[政经重点](../src/mayuan/value-and-surplus.md)。

</details>

## 毛中特与史纲

新民主主义革命与社会主义改造在任务上怎样不同？为什么不能说辛亥革命结束了半殖民地半封建社会？

<details>
<summary>核对并回到教学</summary>

前者完成反帝反封建等民主革命任务，后者推进生产关系的社会主义改造，不能混为同一任务。辛亥革命结束君主专制制度，但未完成反帝反封建任务，不能扩大其成果。回看[毛中特](../src/maozhongte.md)与[史纲](../src/shigang.md)。

</details>

## 习概、思法、时政

“理论观点、基本方略、实践成就、方法论”怎样区分？道德提倡是否自动成为法律义务？同一条新闻为什么不能只有一份固定答案？

<details>
<summary>核对并回到教学</summary>

分别对应十个明确、十四个坚持、十三个方面成就、六个必须坚持的功能层次；还需记准确具体内容。道德提倡不能无依据转成法律强制。同一新闻可呈现不同关系，答案须服从设问对象和指定视角。回看[习概](../src/xigai.md)、[思法](../src/sifa.md)、[时政](../src/shizheng.md)。

</details>
