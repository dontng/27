## 怎么使用

正文用层级、短解释和文本关系图把知识接起来。**看懂一遍不记为掌握**：隔天闭卷解释，再换题，最后进入限时混合题。训练题均注明来源；本项目原创示例用于练机制，不冒充真题、预测题或官方评分标准。

老师的背诵资料将拆成“能回答什么、核心表述、材料怎样接、换问法怎样用”，不是再抄一遍。没有上传的资料不生成伪解析；已有解释若不能帮助独立作答，继续修订。
