## 模块一 · 专题 03 物质与意识的辩证关系（书 P7—P9）

### 1. 意识的起源（书 P7）
- **自然界长期发展的产物**：一切物质具有的反应特性 $\rightarrow$ 刺激感应性 $\rightarrow$ 感觉和心理 $\rightarrow$ 人类意识。
- **社会历史的产物**：
  - **劳动**：起**决定性作用**。
  - **语言**：对意识起**促进作用**（语言是意识的物质外壳）。
  - ⚠️ **老师原话排雷**：如果选项说“意识是被语言所决定的”或“意识的改变取决于词语含义的改变”，**不能选**！起决定作用的是劳动，语言只起促进作用。

### 2. 意识的本质（书 P7 圈二·重点把握）
- **人脑的机能和属性**：
  - 老师提醒：“人脑”画个圈圈，特殊的物质形容的是**人脑**，只有人脑才能产生意识，**意识是为人所独有的**（动物、AI 都不能产生意识）。
- **客观世界的主观映象**：
  - **内容是客观的**（来源于客观世界）；
  - **形式是主观的**；
  - 是**客观内容与主观形式的统一**。
  - ⚠️ **老师原话排雷**：如果选项说意识是对客观世界的“一模一样的反应 / 直观的印象 / 直观反应”，**不能选**！意识是**能动的反映**。

### 3. 意识的能动作用（书 P7—P8）
- 表现在四个方面：目的性计划性、创造性、指导实践改造世界、调控生理。
- ⚠️ **正误原话辨析**：
  - “精神可以替代物质” $\rightarrow$ **一定是错误的**（精神无法直接改变客观现实）。
  - “精神可以转化为物质” $\rightarrow$ **正确**（通过**指导实践**得以转化）。

### 4. 主观能动性与客观规律性（书 P8）
- 规律是客观的，不依赖于人的意志。
- **红线**：人**不能创造规律、消灭规律、改变规律**，人只能**尊重规律、认识规律、利用规律**。
- ⚠️ **排雷**：自然规律对应**“自发”**，社会规律对应**“自觉”**，二者不可张冠李戴。

### 5. 意识与人工智能（书 P8 圈四·高频考点）
- **能做到的**：把人的**“部分”**智能活动机器化（圈出“部分”）。
- **做不到的（选项若改为“能做到”即为经典干扰项）**：
  - 无法真正具备人的意识，不可能取代或超越人类智能；
  - 不具备人类的情感、信念、意志；
  - 不具备社会性。

### 6. 命题分析做题技巧 · 删繁就简法（书 P9）
- **真题干扰项**：“认识的反复性和无限性决定了客观事物的复杂性”。
- **老师解题技巧**：提取核心词：“认识” = 主观，“客观事物复杂性” = 客观。整句话简化为“主观决定客观”，一眼识破是唯心主义错误，直接排除！

## 模块二 · 专题 04 事物的普遍联系和变化发展（书 P10—P11）

> **地位**：唯物辩证法的两大总特征 —— 普遍联系与变化发展。

### 1. 联系的四大特性（书 P10）
- **客观性**：联系是客观的，包括**自在事物的联系**与**人为事物的联系**，都不以人的意志为转移。
- **普遍性**：内部要素、事物之间、整个世界都是普遍联系的统一整体。
- **多样性**：直接联系与间接联系、内部与外部、本质与非本质、必然与偶然。
- **条件性**：
  - 条件对事物发展起**双重作用**（支持或制约）；
  - 条件可以改变，但**必须尊重客观规律，绝不能任意改变**（*老师生活例证*：养花需要光照水分土壤，改变条件必须符合植物客观规律，不能胡来）。

### 2. 发展的实质（书 P11）
- **实质**：**新事物的产生和旧事物的灭亡**。
- **新旧事物的区分**：
  - **根本标志**：在于**是否同历史发展的必然趋势相符合**。
  - ⚠️ 细节：并不取决于形式的新旧和出现时间的先后。**新出现的事物不一定是新事物**；新事物在哲学上等同于“新生事物”。
- **新事物不可战胜的三大原因**：适应变化的环境、对旧事物辩证否定（扬弃）、符合人民群众的利益和要求。
- **过程论**：世界不是既成事物的集合体，而是**过程的集合体**；具体的新事物是暂时的，发展过程是永恒的。

## 模块三 · 老师课上重点点播的经典干扰项清单

| 老师口播引用的干扰项表述 | 正误判断 | 老师原话解析依据 |
| :--- | :---: | :--- |
| “意识是被语言所决定的 / 取决于词语含义的改变” | ❌ 错误 | 起决定作用的是**劳动**（物质层面），语言只起促进作用。 |
| “意识是对客观世界的直观印象 / 直观反应” | ❌ 错误 | 意识是**能动的反映**，不是直观被动的镜像。 |
| “精神可以替代物质” | ❌ 错误 | 精神不能替代物质，但可以通过**指导实践转化为物质**。 |
| “事物之间的联系通常都是人们主观意志赋予的” | ❌ 错误 | 违背了**联系的客观性**，联系不以人的主观意志为转移。 |
| “一切事物的联系都是在人类实践活动中形成的” | ❌ 错误 | 既有自在事物的联系，也有人为事物的联系，**不都是人为形成的**。 |
| “任何事物之间都可以建立起直接联系” | ❌ 错误 | 联系有多样性，既有直接联系，**也有大量间接联系**。 |
