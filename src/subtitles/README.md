## 整理口径

按老师原来的专题顺序展开，保留概念解释、设问、例子、关键词对应、考法和干扰项辨析。删去开场寒暄、励志话、翻页圈画指令、重复的口头确认和无内容转场；相邻的字幕断句合并为自然段，不使用表格。明显的转写错字按上下文校正，为理解和记忆补充少量判断方法、工作例子与闭卷自检，明确标注“辅助理解与自检（整理补充）”；原视频未提供的课后题不补写、不冒充老师原题。

Word 原件原名、原字节保留，方便核对。讲稿不是逐字逐句校勘本，也不是按现行教材重新审定的知识文本；老师关于分值、考频、时政的判断保留为本课表述；明显不严谨的口头简化加以限缩或注明辅助理解，避免把口诀当作通用判题规则。仓库内原有错误下册不作为本次依据。
