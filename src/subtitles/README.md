# 带背视频字幕与旁听笔记

保存用户上传的带背视频字幕，供后续检索、核对讲解和关联书内专题使用。已基于原始字幕整理出结构化、有着重标注与考点排雷的**带背旁听笔记**。

## 文件保存规则

- 接收 `.srt`、`.vtt`、`.ass`、`.txt`、`.json` 等字幕文件，保留原始内容和已有时间轴存放于 `bank/` 目录下。
- 原始文件保留原名；遇到重名时，按期数、视频标题或上传批次区分，不覆盖已有文件。
- 整理后的 Markdown 笔记独立存放于本目录，忠实还原主讲老师（韩雪老师）的授课脉络、圈画重点、生动例证与排雷清单，不引入无关的二次改写。
- 仓库现有错误下册不作为匹配依据。
