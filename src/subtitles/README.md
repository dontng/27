# 带背视频字幕

保存用户上传的带背视频字幕，供后续检索、核对讲解和关联书内专题使用。

## 文件保存

- 接收 `.srt`、`.vtt`、`.ass`、`.txt`、`.json` 等字幕文件，保留原始内容和已有时间轴。
- 原始文件保留原名；遇到重名时，按期数、视频标题或上传批次区分，不覆盖已有文件。
- 如需整理成 Markdown，另存对应文件；校对和补充说明与原字幕分开。
- 能确定时记录视频标题、期数、来源链接和对应专题；缺失信息先留待确认，不推测补齐。

## 后续使用

字幕导入后，在这里追加文件索引，并关联到[上册目录](../肖秀荣背诵手册-上册目录.md)和[专题 PDF](../pdf/README.md)。字幕与书本有差异时保留差异，核对后再处理。
