## 拟定的颗粒度

```text
毛中特
├─ 毛泽东思想 ── 新民主主义革命理论、社会主义改造与建设初步探索
└─ 改革开放理论体系
   ├─ 邓小平理论
   ├─ "三个代表"重要思想
   └─ 科学发展观
```

**为什么这样切**：和[马原](../mayuan/README.md)里马哲→政经→科社的切法一样，不按"一本书的章节顺序"切，按"理论回答的是哪个历史阶段的核心问题"切——毛泽东思想回答的是"革命和建国初期怎么办"，改革开放理论体系回答的是"建国后怎样建设、怎样改革"，这两组问题性质不同，不该混在一个颗粒度里。

习近平新时代中国特色社会主义思想单独算一科（见[新思想](../xinsixiang/README.md)），不塞进毛中特里，虽然官方课程把两者算一门课，但应试复习颗粒度上分开处理更清楚。

这个切法是我按通行教材体系的判断，不是定论——真正排到这科时，如果你发现切得不顺手，随时可以改。
