## 审核方法与证据

1. 从交付Markdown独立解析193题，不调用`build.py`，检查题号、选项、答案及来源链接。
2. 重新从PDF渲染页面并用Tesseract 4.1.1进行中文OCR：`chi_sim`、`--psm 6`，渲染倍率3.5，裁去页眉和底边，裁剪区域为PDF坐标`(0, 60, width, height-12)`。输入文件路径与SHA-256在[review.json](review.json)中。
3. 将第二轮OCR与审核前交付正文按汉字、数字对齐，得到177个差异片段，逐处回看扫描页。多数是OCR题号或字形误识别；标点、空格和两轮OCR共有的错误另外目视核对。OCR本身不作为最终依据。
4. 对照PDF63—64页重新按行读取193项答案，以独立记录和交付Markdown逐项比较。
5. 以从扫描页读出的逐页题号清单检查每题页码，记录审核后逐题文本摘要及全部文件校验值。
