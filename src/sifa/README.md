## 拟定的颗粒度

```text
思法（思想道德与法治）
├─ 思想部分 ── 人生观、理想信念、中国精神、社会主义核心价值观、道德规范
└─ 法治部分 ── 法律基本原理、宪法、具体部门法要点
```

**为什么这样切**：这两部分考察方式本质不同——思想部分多是"用某种观念/价值判断评析材料中的行为选择"，法治部分多是"用具体法律规范判断材料中的行为是否合法/该如何定性"，判断依据的性质不一样（价值判断 vs 规范适用），混在一起容易出现"用道德标准去判断法律问题"或反过来的错位，分开颗粒度管理能提前防住这个混淆。
