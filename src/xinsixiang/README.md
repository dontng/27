```text
新思想（习近平新时代中国特色社会主义思想）
├─ 方向与目标 ── 鲜明主题、历史地位、新时代的历史方位
```

**为什么这样切**：这三层是"要去哪→靠什么领域的任务去到→靠什么条件和保证能落地"的递进关系，不是五位一体和"条件保证"并列堆砌——材料题经常考的是某具体领域任务（比如生态文明）要怎样接到"坚持和发展中国特色社会主义"这个总方向上，颗粒度上先把这条递进链立住，比先背每个领域的细则更有用。
