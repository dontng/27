# 思法：方向、价值、道德、法律各解决什么

**先把问题分层，避免看到正面词就全部选。**方向正确、道德高尚、法律允许并不是同一句判断。

```text
个人如何在社会中生活与行动
├─ 人生观：目的、态度、价值
├─ 理想信念：追求什么，怎样坚持与实现
├─ 中国精神：民族精神与时代精神
├─ 核心价值观：国家、社会、个人层面的价值要求
├─ 道德：行为的善恶评价与规范
└─ 法律：权利义务、制度程序与国家强制保障
```

## 人生观：三个问题不能混答

- **人生目的**：为什么活着，追求什么。
- **人生态度**：以什么状态对待生活。
- **人生价值**：怎样评价人生的意义与贡献。

坚持个人价值与社会价值相联系，不能把人生价值等同于收入、头衔，也不能理解成否定个人合理需要。评价价值和实现价值有不同问题：前者看标准，后者还要看社会条件与个人努力。

## 理想信念：现实与理想怎么接

理想来自现实，又超越现有现实；实现理想依靠实践。现实时有困难，不等于理想没有意义；有了理想，也不等于自动实现。个人理想与社会理想相联系，不表示二者没有区别。

材料问“怎样实现”，应接到认识条件、付诸行动和持续努力，不能只写“理想很重要”。这与马原实践观相通，但若明确问理想与现实的关系，答案主体仍须回应这组关系。

## 精神与价值要求

民族精神以爱国主义为核心，时代精神以改革创新为核心；共同构成中国精神的重要内容。社会主义核心价值观的国家、社会、个人层面分别有对应表述，不能在层面配对上凭熟悉感混选。

理解这些内容应落到行动对象：职业岗位、公共生活、家庭、社会实践等。不能把所有正面行为都简单称为同一种精神，也不能把“个人层面”理解成与国家社会无关。

## 道德：核心、原则、领域

- 社会主义道德以为人民服务为核心，以集体主义为原则。核心与原则不是可互换的两个标签。
- 社会公德、职业道德、家庭美德、个人品德，按行为场景与规范归位；个人品德不是与其他领域隔绝的一块。
- 道德修养须进入实践，不能只停在评价他人。

## 法律：与道德联系，但不能合并

法律依靠国家强制力保证实施，道德还通过社会舆论、传统习惯、内心信念等发挥作用。二者共同参与社会治理，不能由“道德上值得提倡”直接推出“法律强制要求”，也不能由“不违法”推出“道德上必然优秀”。

学习法律先抓法治思维、宪法地位、权利义务与依法办事。涉及具体法律条文、责任和程序时，必须核对现行法律；本页不提供个案法律意见。

## 原创辨析

有人说：“志愿服务值得提倡，所以每个人不参加志愿服务都违法。”错在哪里？

<details>
<summary>核对</summary>

由道德评价直接推出法律义务，缺少法律依据。可以肯定志愿服务的社会价值，但不能据此认定所有不参与行为违法。若材料另有特定法定义务，要根据该义务判断，不沿用本例的结论。
