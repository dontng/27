## 当前状态

只有[马原](mayuan/README.md)真正展开了内容（理解正文+速记卡），且只验证到"概念能不能串成一条链"这一层，还没有拿真实材料题验证过能不能转化成考场得分——这是下一步要做的事，不是知识覆盖的扩大。

其余五科目前只是**颗粒度规划**（切成几块、为什么这样切），没有正文。不预先铺出空的正文占位——之前这个仓库犯过这个错误（先搭好看的骨架，再慢慢填，大部分格子长期是空的），这次反过来：哪个颗粒度被真实题目或你的真实卡点命中了，才去展开那一块。

## 这套结构解决的是什么、不解决什么

这里管理的是**理解**和**记忆**两层（为什么是这样、怎么压缩成能默写的句子）。更上层还有**答题**（设问→模板，跨学科部分已经单独放在 [answer-method.md](answer-method.md)）、**诊断**（拿真实材料限时作答，当场找断点）、**复习**（间隔重复的调度）——这几层目前不预先搭文件夹，等真的有诊断数据或复习需求时再决定放在哪。
