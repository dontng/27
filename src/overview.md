# 政治各科怎样连起来

**先分清每门课在回答什么，再把共同问题接起来。**同一个词在不同课程里出现，不表示答案可以互换。

```text
考研政治
├─ 马原：解释一般规律与运行机制
├─ 毛中特：理论怎样回答中国不同阶段的问题
├─ 习概：新时代的方向、目标与实践部署
├─ 史纲：历史进程、探索与选择的依据
├─ 思法：个人怎样理解价值、道德与法律
└─ 时政与当代：现实事件、政策与国际背景
```

这是学习分工，不是今年考试大纲的完整目录。课程结构参考[高教社公开教材目录](../sources/README.md)，年度新增内容须另核。

## 用“改革”看不同视角

- **马原**问：为什么社会需要改革？接到生产关系与生产力、上层建筑与经济基础的矛盾运动。
- **毛中特**问：改革开放在中国特色社会主义探索中怎样提出和发展？接到历史条件与相应理论。
- **习概**问：新时代全面深化改革的目标、方向与部署是什么？需要准确表述及当前文件依据。
- **史纲**问：某次转折如何发生，改变了什么？需要时间、事件、实际历史作用。
- **思法**问：怎样发挥改革创新精神？需要主体行为、责任与实践。
- **时政**问：某次会议具体提出什么？需要核实该次文件，不能拿任何一句“改革很重要”替代。

**辨别入口是设问要求，不是看到关键词就选课程。**材料说技术创新，既可能要求用生产力原理解释，也可能要求回答创新驱动发展；先看题目要求的视角。

## 三条跨科联系

- **实践与理论**：马原解释实践与认识的关系；毛中特、习概呈现理论与中国实践的结合；史纲提供具体历史证据。
- **人民与发展**：马原解释人民群众的历史作用；相关中国化理论说明人民立场与发展目标；思法讨论个人价值如何在社会实践中实现。
- **制度与行动**：马原解释社会结构；毛中特、习概说明具体制度与建设任务；史纲呈现其形成，思法帮助理解规范如何进入行为。

这些联系用于理解，不是万能套话。史纲问某事件的历史意义，不能只答“人民群众是历史创造者”；马原明确要求原理分析，也不能只抄时政文件。

## 学到什么程度才有用

- 读主线：能说清“这一科在解释什么”。
- 读重点页：能分清两个相近概念，说明条件。
- 做选择：没有章节提示也能逐项判断。
- 写分析：能先形成准确骨架，再写成回应设问的答案。
