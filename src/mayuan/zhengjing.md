# 政治经济学：资本主义生产方式的具体机制

[上一节：马克思主义哲学](mazhe.md) · [学科总览](README.md) · 下一节：[科学社会主义](keshe.md)

**接上一节的接口**：历史唯物主义要求研究生产关系，资本主义社会的生产关系首先表现为商品交换关系。所以这一节从商品分析开始，一路推到资本主义的基本矛盾——这条链不是知识点列表，是一条层层深入的推导。

```text
商品(使用价值+价值) → 劳动力成为商品 → 剩余价值(c+v+m)
   │
   ├─ 剩余价值率 m/v
   ├─ 利润率 m/(c+v)
   └─ 三种生产方式：绝对／相对／超额
   │
资本积累 → 资本有机构成↑ → 相对过剩人口
   │
社会再生产(两大部类比例) ──┐
   │                      │
平均利润／生产价格 ────────┤──→ 资本主义基本矛盾
   │                      │     (生产社会化 vs 私人占有)
   └──────────────────────┘          │
                                      ▼
                                 经济危机(生产过剩)
```

这张图是整节的骨架，考场上先把它默出来，再往对应节点填材料——这比直接背每一段文字定义更先决，也更不容易把"资本积累"和"资本循环"这类名字相近但层级不同的概念位置搞混。

## 商品二因素与劳动二重性
- **使用价值**：商品满足人的需要的属性，物质承担者。
- **价值**：凝结在商品中的无差别人类劳动，体现商品生产者之间的社会关系——**这是历史唯物主义"生产关系"在商品层面的具体落点**。
- 对应**劳动二重性**：具体劳动创造使用价值，抽象劳动形成价值。同一次劳动的两个方面，不是两次劳动。

## 价值规律
商品价值量由**社会必要劳动时间**决定（现有正常生产条件、社会平均熟练程度和劳动强度下制造某使用价值所需的时间），不是由个别劳动时间决定。价值规律要求商品按价值量进行交换，通过价格围绕价值波动调节资源配置。

## 货币转化为资本的关键：劳动力成为商品
普通商品交换不能解释剩余价值的普遍来源（等价交换不可能靠买卖加价获得系统性增殖）。**转折点是劳动力成为商品**：劳动者有人身自由却丧失生产资料，必须靠出卖劳动力维持生活。资本家购买的是劳动力（能力），使用劳动力所产生的结果（劳动）能创造超过劳动力自身价值的新价值——这就是剩余价值的秘密所在。

## 剩余价值的生产

```text
商品价值 c ＋ v ＋ m
├─ c：不变资本，生产资料转移的已有价值（不创造新价值）
└─ v＋m：活劳动创造的新价值
   ├─ v：可变资本，补偿劳动力价值（必要劳动）
   └─ m：剩余价值（剩余劳动）
```

- **绝对剩余价值**：必要劳动时间不变，延长工作日增加剩余劳动时间。
- **相对剩余价值**：工作日不变，提高社会劳动生产率、降低劳动力价值，缩短必要劳动时间。
- **超额剩余价值**：个别企业生产率高于社会平均，商品个别价值低于社会价值的差额——这是相对剩余价值实现的中间环节，不是另一种独立类型。

**剩余价值率** m/v，反映剥削程度；**利润率** m/(c+v)，分母是全部预付资本，不是产值。

## 资本积累与资本有机构成
剩余价值转化为资本进行再投资，形成资本积累。随积累发展，不变资本相对可变资本的比例（**资本有机构成**）提高，对劳动力的相对需求下降，形成**相对过剩人口**——这不是"资本家故意裁员"的道德判断，是资本积累的客观趋势导致的结构性结果。

## 资本循环、周转与社会再生产
单个资本要经过购买、生产、售卖三个阶段、三种职能形式（货币资本、生产资本、商品资本）的循环才能实现增殖；周转速度影响年剩余价值量。社会再生产要解决两大部类（生产资料、消费资料）之间按比例交换的问题，比例失调是危机的结构性条件之一。

## 利润、平均利润与生产价格
剩余价值在观念上转化为利润后，掩盖了"利润从剩余劳动而来"这一来源，表现为全部预付资本的产物。不同部门利润率本来不同，但资本在部门间自由转移、竞争会使利润率趋向平均化，形成**平均利润**，商品按"成本价格＋平均利润"即**生产价格**出售——这是价值规律在竞争条件下的转化形式，不是价值规律失效。

## 资本主义基本矛盾与经济危机
资本主义基本矛盾：**生产社会化**与**生产资料资本主义私人占有**之间的矛盾——这正是马哲里"对立统一规律"和"生产力与生产关系矛盾"两条线在资本主义社会的最终汇合点（见[马克思主义哲学](mazhe.md)），不是一个新冒出来的孤立结论。这一矛盾具体展开为：

- 生产无限扩大趋势 与 劳动者有支付能力需求相对不足 的矛盾
- 个别企业内部有计划 与 整个社会生产无政府状态 的矛盾

经济危机的实质是**生产过剩**——相对于有支付能力的需求过剩，不是相对于人的实际需要过剩（仓库积压与有人缺生活资料可以同时存在，不矛盾）。危机周期性爆发，是资本主义基本矛盾阶段性激化又阶段性缓和的表现。
