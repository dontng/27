# 马原：从世界到社会

[上一节：全科关系](../overview.md) · [下一节：历史唯物主义进入政经](history-to-capital.md)

**前面的哲学提供观察方法，后面的部分用它分析社会。**难点往往出现在抽象原理变成社会结构和经济机制时：名词增多，而且同一事物要从不同关系研究。

```text
世界客观存在
├─ 物质与意识：现实与人的能动活动是什么关系？
├─ 辩证法：事物怎样联系和发展？
└─ 实践与认识：怎样形成、检验和发展认识？
       ↓ 把分析转向人类社会
物质生产是社会存在和发展的基础
├─ 历史唯物主义：生产、制度、观念怎样相互作用？
└─ 政治经济学：资本主义生产关系怎样具体运行？
       ↓ 依据社会矛盾研究发展方向
科学社会主义：社会变革的条件、原则与实践道路
```

## 前半部先保住这些判断

- **物质决定意识**：从客观实际出发；意识的能动作用通过实践实现，不是想法直接改变世界。
- **联系与发展**：联系有客观条件，不能任意攀附；发展不能等同于任何变化。
- **矛盾**：对立与统一同时成立；普遍性不能取消特殊性，具体分析不能变成随意处理。
- **主次关系**：主要矛盾属于多个矛盾的比较；矛盾主要方面属于同一矛盾内部双方的比较。
- **量变、质变、否定**：积累与突破相联系，保持性质有“度”；辩证否定是扬弃，不是全盘抛弃。
- **实践与认识**：实践是认识的基础；认识能反作用于实践。知识可从他人获得，最终来源仍是实践。
- **真理与价值**：认识是否符合客观对象，与对象能否满足主体需要，是不同问题；实践须把二者统一。

不是每道题都要同时调用这些原理。先识别材料呈现的关系，再选相关内容；“尊重规律＋发挥能动性”不能覆盖所有马原设问。

## 历史唯物主义增加了什么

个人活动之外，出现生产方式、生产关系、经济基础、上层建筑、社会存在、社会意识。它们不在同一层：有的说明生产，有的说明制度，有的说明社会的物质与精神方面。

先读[历史唯物主义进入政经](history-to-capital.md)，用同一例子把这些层次归位，再进入价值与剩余价值。

## 政经怎样围绕中心展开

- **商品与劳动**：商品怎样具有使用价值与价值？价值量由什么决定？
- **货币与资本**：货币何时转化为资本？关键是劳动力成为商品。
- **剩余价值生产**：为什么等价交换条件下仍能出现剩余价值？
- **资本积累**：把剩余价值再转为资本，怎样影响规模与资本构成？
- **资本循环与周转**：资本怎样经过购买、生产、销售完成运动，速度怎样影响增殖？
- **社会再生产**：不同部门如何实现产品与价值的补偿，扩大生产有哪些条件？
- **利润等形式**：剩余价值怎样表现、分配？不把表现形式误当来源。
- **资本主义发展**：竞争、集中、垄断与调整怎样发展，又没有根本消除什么矛盾？

先把[价值与剩余价值](value-and-surplus.md)吃透，再读[资本循环、周转与社会再生产](capital-movement.md)，最后接到[利润、分配与危机](profit-and-crisis.md)。已有连续机制与简化数例，扩大再生产、地租等细目尚未逐项教学。

## 科学社会主义怎样接上

唯物史观说明社会发展的规律，剩余价值学说揭示资本主义的经济关系，这两大发现使社会主义由空想成为科学。这里从愿望进入条件与机制研究，不等于历史在固定日期自动完成。

- 社会主义基本原则：规定根本方向，不能拿某种具体模式替代全部原则。
- 建设道路：具体条件不同，道路具有多样性；探索具有长期性和曲折性。
- 共产主义：生产力高度发展、生产资料公有制、人的自由而全面发展等目标相联系；不能与当前阶段混同。

继续读[科学社会主义：原则、道路与阶段](socialism.md)。
