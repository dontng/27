# 政经：速记卡（重点区——去年丢分区域）

[理解正文](zhengjing.md) · [学科总览](README.md)

把[政治经济学](zhengjing.md)的原理压成能直接默写的句子。怎么判断该用哪张卡、写了很多字为什么还可能不给分，看跨学科通用的[答题方法](../answer-method.md)。

### 卡7·商品二因素与劳动二重性
- **默写句**：商品具有使用价值和价值二因素，由劳动二重性决定：具体劳动创造使用价值，抽象劳动形成价值。
- **触发信号**：材料问"商品价值从哪来""为什么说价值体现社会关系"。
- **接材料句式**：材料中___劳动，其具体形式创造了___使用价值，同时作为无差别人类劳动的耗费形成了价值，这是劳动二重性的体现。

### 卡8·价值规律
- **默写句**：价值规律是商品按社会必要劳动时间决定的价值量进行交换的规律，价格围绕价值波动，调节资源配置。
- **触发信号**：材料涉及"价格波动""某商品供求变化影响价格"。
- **接材料句式**：材料中___（价格现象）是价值规律中价格围绕价值波动这一表现形式，其背后调节的是___资源在部门间的配置。

### 卡9·剩余价值的来源
- **默写句**：劳动力成为商品是货币转化为资本的前提；劳动力的使用即劳动创造的新价值，超过劳动力自身价值的部分形成剩余价值，这是资本主义剥削的实质。
- **触发信号**：材料涉及"工资与创造价值的差额""雇佣劳动关系"。
- **接材料句式**：材料中___（雇佣劳动情境）表明工人创造的新价值___，超过其获得的___（工资/劳动力价值）部分即为剩余价值，由资本家无偿占有。

### 卡10·剩余价值生产的三种方式
- **默写句**：绝对剩余价值靠延长工作日获得；相对剩余价值靠提高社会劳动生产率、缩短必要劳动时间获得；超额剩余价值是个别企业生产率高于社会平均时获得的差额，是相对剩余价值实现的中间环节。
- **触发信号**：材料出现"延长工时""技术升级/效率提高"。
- **接材料句式**：材料中___（技术升级/效率提高）属于相对剩余价值生产方式，其中企业率先改进、暂时获得超出平均水平收益的部分，属于超额剩余价值；若材料讲延长工作时间，则对应绝对剩余价值。

### 卡11·资本积累与资本有机构成
- **默写句**：剩余价值转化为资本进行再投资形成资本积累；随积累发展，资本有机构成（不变资本与可变资本的比例）提高，导致相对过剩人口。
- **触发信号**：材料涉及"企业规模扩大、设备投入增加、用工减少"。
- **接材料句式**：材料中___（设备/资本投入增加而用工相对减少）体现了资本有机构成提高的趋势，是资本积累的客观结果，不是个别企业主观恶意裁员的孤立行为。

### 卡12·社会再生产两大部类
- **默写句**：社会总产品按用途分为生产资料和消费资料两大部类，两大部类之间必须保持一定比例关系才能实现社会再生产的顺利进行，比例失调是危机的结构性条件之一。
- **触发信号**：材料涉及"产能过剩、某行业供需失衡"。
- **接材料句式**：材料中___行业的产能/供需状况，涉及两大部类之间比例关系是否协调，比例失调会影响社会再生产的顺利进行。

### 卡13·平均利润与生产价格
- **默写句**：不同部门利润率本不相同，资本在部门间自由转移和竞争使利润率趋向平均化，形成平均利润；商品按成本价格加平均利润即生产价格出售，这是价值规律在竞争条件下的转化形式。
- **触发信号**：材料涉及"资本从一个行业转向另一个行业追逐更高利润"。
- **接材料句式**：材料中___（资本转移现象）体现了资本为追逐更高利润率在部门间流动，这一过程推动利润率平均化、形成平均利润，并不意味着价值规律失效，而是其转化形式。

### 卡14·资本主义基本矛盾与经济危机
- **默写句**：资本主义基本矛盾是生产社会化与生产资料资本主义私人占有之间的矛盾，具体展开为生产无限扩大趋势与劳动者有支付能力需求相对不足的矛盾，以及个别企业有计划与社会生产无政府状态的矛盾；经济危机的实质是生产过剩，即相对于有支付能力需求的过剩。
- **触发信号**：材料涉及"产能过剩却同时有人消费不足""经济周期性波动"。
- **接材料句式**：材料中___现象体现了生产社会化程度提高与生产资料私人占有之间的矛盾，具体表现为___（无限扩大生产/需求不足/生产无计划），这是资本主义基本矛盾的具体展开，不是孤立的管理失误。

## 政经链条记忆口诀（考场上先在草稿纸上默写这张图，再往答案里填）

```text
商品(使用价值+价值) → 劳动力成为商品 → 剩余价值(c+v+m)
   │
   ├─ 剩余价值率 m/v
   ├─ 利润率 m/(c+v)
   └─ 三种生产方式：绝对／相对／超额
   │
资本积累 → 资本有机构成↑ → 相对过剩人口
   │
社会再生产(两大部类比例) ──┐
   │                      │
平均利润／生产价格 ────────┤──→ 资本主义基本矛盾
   │                      │     (生产社会化 vs 私人占有)
   └──────────────────────┘          │
                                      ▼
                                 经济危机(生产过剩)
```

背这张图比背每张卡的完整定义更先决——考场上先把这个骨架默出来，再往对应节点填材料，不容易漏答得分点。
