## 拟定的颗粒度

```text
史纲（中国近现代史纲要）
├─ 旧民主主义革命时期（1840—1919）── 历史处境：为什么旧式救国方案都失败了
├─ 新民主主义革命时期（1919—1949）── 不同探索：各政治力量的方案与较量
├─ 社会主义革命和建设时期（1949—1978）── 转折与选择：怎样建立、怎样探索
└─ 改革开放和社会主义现代化建设新时期（1978—）── 建设与改革：怎样纠偏、怎样发展
```

**为什么这样切**：按时间分期，是因为史纲的材料分析题本质是"给一段历史材料，判断它属于哪个阶段、当时的核心矛盾和历史任务是什么"，颗粒度按历史分期切，直接对应"材料发生在哪个时间段"这个判断起点；不按"人物/事件专题"切，是因为专题切法容易让同一时期的材料被拆散到不同文件，反而破坏了"同一阶段内各事件互相关联"的结构。

每个时期内部还会再细分核心事件和转折点，但那是填内容时才展开的下一层，不在这里预先列。
