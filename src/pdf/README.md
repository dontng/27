## 接力与复现

输入文件已在仓库 references/xiaoxiurong/pdf 中保存，不重复上传。[_work/inputs.json](_work/inputs.json) 固定输入版本、路径和SHA-256；[_work/validation.json](_work/validation.json) 记录逐文件校验；[_work/progress.json](_work/progress.json) 记录本提交包含的批次。[_work/previews](_work/previews) 保存逐专题起始页核对图，保留页底标题等边界证据。

安装 PyMuPDF 和 numpy 后，在仓库根目录执行：

```bash
python tools/split_xiaoxiurong.py --limit 70
```

脚本先核对来源校验值，再按清单提取整页并遮盖页边群号，重新打开每份文件核对页数和页面尺寸，逐页比较遮盖区域以外的渲染结果。--limit 可用于分批恢复。校验通过后用 tools/index_topic_pdfs.py 更新索引与进度，再按 AGENTS.md 的署名规则分批提交到main。
