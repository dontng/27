# 分析题通用答题方法（跨学科，不属于任何一科的知识内容）

这页讲的不是"哪个原理是什么"，是"不管考哪一科，材料发到你手上之后，脑子里该走哪几步"。各科知识脉络在各自目录下（[马原](mayuan/README.md) 等），各科的速记卡只负责"这科有哪些原理可以拿来用"，怎么把原理和材料接起来、怎么避免写了很多字还是0分，统一在这页定，不在每科重复一遍。

## 为什么写了很多字可能还是不给分

阅卷按点给分，不按字数、态度、流畅度评分。三种最常见的0分/低分写法：

1. **只描述材料现象，没有点出原理术语**——材料讲"某企业技术升级"，你从头到尾讲"技术进步很好、企业效益提升"，没有一句"这体现了XX原理"，阅卷找不到得分点。
2. **原理选错**——材料考的是"生产关系"，你却整段讲"意识能动性"，原理和设问对不上，再怎么写都不在分点上。
3. **原理和材料两段互不呼应**——先抄一段原理定义，再另起一段讲材料，中间没有一句把两者接起来的话，阅卷无法确认你是"套用"还是"真的用这个原理分析了材料"。

## 保命三句式（任何一道分析题都先做这三步）

```text
① 这道题问的是"为什么/有什么意义/体现了什么/怎么办"——先定设问类型
② 点名原理关键词——术语要准，不能用大白话代替专业术语
③ 一句话把材料接到原理上——"材料中的XX，正是XX原理在XX方面的体现"
```

## 设问类型 → 原理定位流程（先判断，再翻该科的速记卡）

```text
"为什么/什么原因"  → 找"决定"关系的原理卡（通常是XX决定XX这一类）
"有什么意义/影响"  → 定位到该科的"基本矛盾/核心规律"卡，说明材料如何影响矛盾的激化或缓和
"体现了什么原理"    → 逐句对应概念定义，材料一句，原理一句，交替写
"怎么看待/怎样评价" → 先判断材料观点对不对，再用对应卡反驳或支持，不能只叙述不下判断
"怎么办/如何应对"   → 回到该科的根本规律，不展开具体政策（超纲且容易编造）
```

## 验证这套方法有没有用：必须拿真实材料现场写

脱离具体题目的通用流程只是脚手架，**真正检验"记住了没有、会不会用"，必须拿一道实际材料题限时现场写**，然后看具体是哪一步断的（认不出原理 / 认出来但选项措辞绕晕了 / 认出来但组织答案的速度跟不上）。这件事不写成文件，在对话里直接做。
