## 专题一：社会主义改造理论（三大改造考场铁律）

### 1. 党在过渡时期的总路线（“一化三改”）

$$\textbf{总路线} = \underbrace{\textbf{逐步实现国家的社会主义工业化}}_{\textbf{主体}} \ + \ \underbrace{\textbf{逐步实现对农业、手工业和资本主义工商业的社会主义改造}}_{\textbf{两翼}}$$

### 2. 农业、手工业与工商业改造阶段性质全览表

| 改造对象 | 组织形式 / 发展步骤 | 性质与特征（考场必考点） |
| :--- | :--- | :--- |
| **农业改造**<br>（原则：自愿互利、典型示范、国家帮助） | 1. **互助组** | 具有**社会主义萌芽性质**（土地仍归私有）。 |
| | 2. **初级农业生产合作社** | 具有**半社会主义性质**（土地入股、统一经营、按劳分配与土地分红结合）。 |
| | 3. **高级农业生产合作社** | 具有**完全的社会主义性质**（土地等主要生产资料公有，按劳分配）。 |
| **手工业改造** | 手工业生产合作小组 $\rightarrow$ 手工业供销合作社 $\rightarrow$ **手工业生产合作社** | 由社会主义萌芽到半社会主义，最终实现完全社会主义公有制。 |
| **资本主义工商业改造**<br>（实行**和平赎买**） | 1. **初级形式国家资本主义**（委托加工、计划订货、统购包销） | 生产受国家控制，流通在国家计划内。 |
| | 2. **个别企业公私合营** | 利润分配实行**“四马分肥”**（国家所得税、企业公积金、职工福利奖金、资方红利）；具有**半社会主义性质**。 |
| | 3. **全行业公私合营** | 资本家领取**定息**（年息5%）；生产关系发生了根本变化，具有**完全的社会主义性质**。 |

* **1956 年三大改造完成的历史意义**：
  > 标志着**社会主义基本制度在我国确立**，我国从新民主主义社会跨入了**社会主义初级阶段**。

## 专题二：邓小平理论与中特理论体系基石

### 1. 邓小平理论的首要基本理论问题与本质论

* **首要的基本理论问题**：**“什么是社会主义、怎样建设社会主义”**。
* **社会主义的本质（南方谈话完整概括）**：
  $$\textbf{解放生产力，发展生产力，消灭剥削，消除两极分化，最终达到共同富裕}$$
  - **生产力层面（基础与目标）**：解放和发展生产力；
  - **生产关系层面（途径与保障）**：消灭剥削、消除两极分化；
  - **根本目标**：实现共同富裕。

---

### 2. 社会主义初级阶段理论与基本路线

* **初级阶段的科学涵义**：
  1. 我国社会已经是社会主义社会，我们必须坚持而不能离开社会主义；
  2. 我国的社会主义社会还处在初级阶段，我们必须从这个实际出发，而不能超越这个阶段。
  > ⚠️ **初级阶段的起止时间**：从 1956 年生产资料私有制社会主义改造基本完成，到 21 世纪中叶基本实现现代化，至少需要一百年。
* **党在社会主义初级阶段的基本路线（“一个中心、两个基本点”）**：
  $$\textbf{以经济建设为中心（兴国之要），坚持四项基本原则（立国之本），坚持改革开放（强国之路）}$$

---

### 3. 社会主义市场经济理论的重大突破

* **核心理论突破（破除把市场等同于资本主义的传统观念）**：
  - 计划多一点还是市场多一点，**不是社会主义与资本主义的本质区别**；
  - **计划和市场都是经济手段**；资本主义有计划，社会主义也有市场。
* **确立目标**：1992 年中共十四大明确提出，我国经济体制改革的目标是**建立社会主义市场经济体制**。

---

### 4. “三个代表”重要思想与科学发展观核心定位

* **“三个代表”重要思想的核心观点**：
  - 代表中国先进生产力的发展要求；
  - 代表中国先进文化的前进方向；
  - 代表中国最广大人民的根本利益。
* **科学发展观的科学内涵**：
  - **第一要义**：**发展**；
  - **核心立场**：**以人为本**；
  - **基本要求**：**全面协调可持续**；
  - **根本方法**：**统筹兼顾**。
