## 专题一：新时代社会主要矛盾与“两个结合”

### 1. 新时代社会主要矛盾（客观题必背）

* **我国社会主要矛盾的转化**：
  $$\textbf{人民日益增长的美好生活需要} \quad \longleftrightarrow \quad \textbf{不平衡不充分的发展}$$
* **“两个没有变”的科学判断**：
  - 我国仍处于并将长期处于**社会主义初级阶段的基本国情没有变**；
  - 我国是**世界最大发展中国家的国际地位没有变**。

---

### 2. “两个结合”的深刻内涵与“魂脉 / 根脉”排雷

习近平总书记在党的二十大报告中指出，坚持把马克思主义基本原理**同中国具体实际相结合、同中华优秀传统文化相结合**。

| 概念范畴 | 官方唯一正确定位 | 考场绝对排坑点 |
| :--- | :--- | :--- |
| **马克思主义** | 坚守的**“魂脉”**（思想武器与科学真理） | ❌ **错项（倒反天罡）**：“中华优秀传统文化是魂脉” $\rightarrow$ **错！** |
| **中华优秀传统文化** | 坚守的**“根脉”**（中华民族的根基与文化基因） | ❌ **错项**：“马克思主义是根脉” $\rightarrow$ **错！** |

* **“第二个结合”的历史意义**：
  - 是又一次的思想解放；
  - 表明我们党对中国道路、理论、制度的认识达到了新高度，表明我们党的历史自信、文化自信达到了新高度，表明我们党在传承中华优秀传统文化中推进文化创新的自觉性达到了新高度。

## 专题二：“六个必须坚持”（世界观与方法论做题对应术）

“六个必须坚持”是习近平新时代中国特色社会主义思想的立场观点方法：

| 范畴 | 核心题眼与对应做题技巧 |
| :--- | :--- |
| **必须坚持人民至上** | 材料涉及“以人民为中心”、“把人民放在最高位置”、“江山就是人民，人民就是江山”。 |
| **必须坚持自信自立** | 材料强调“中国的事情必须由中国人民自己作主张”、“走自己的路”、“中国式现代化不照搬西方”。 |

| **必须坚持胸怀天下** | 材料强调“构建人类命运共同体、一带一路、全球发展倡议、为人类谋进步、为世界谋大同”。 |

## 专题三：中国式现代化理论与战略安排

### 1. 中国式现代化的中国特色（五大特色口诀：人规、共富、两文、自和、和发）

1. **人口规模巨大的现代化**（中国式现代化的显著特征）；
2. **全体人民共同富裕的现代化**（中国式现代化的本质特征）；
3. **物质文明和精神文明相协调的现代化**（中国式现代化的崇高追求）；
4. **人与自然和谐共生的现代化**（中国式现代化的鲜明特点）；
5. **走和平发展道路的现代化**（中国式现代化的突出优势）。

### 2. 中国式现代化的本质要求与首要任务

* **本质要求**：坚持中国共产党领导，坚持中国特色社会主义，实现高质量发展，发展全过程人民民主，丰富人民精神世界，实现全体人民共同富裕，促进人与自然和谐共生，推动构建人类命运共同体，创造人类文明新形态。
* **首要任务**：**高质量发展是全面建设社会主义现代化国家的首要任务**。
* **两步走战略安排**：
  - 从 2020 年到 2035 年：**基本实现社会主义现代化**；
  - 从 2035 年到本世纪中叶：**把我国建成富强民主文明和谐美丽的社会主义现代化强国**。
