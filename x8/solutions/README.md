## 刷完 8 套的整体体感与通用经验（无剧透）

1. **整体难度结构**：基本盘（常规马原、经典史纲、德法核心概念）非常稳，真正拉开分数差距的，主要是**概念细节的精确边界**、**史纲时间轴与定性匹配**，以及**当年最新时政文件的精准提法**。
2. **最高频的三类失分陷阱**：
   - **定语/定位“张冠李戴”**：把 A 概念的专属定语（如“根本”“首要”“显著标志”“枢纽”“骨干”）安到 B 概念头上；表面看句句都对，一核对主语就露馅。
   - **时间轴与阶段错位**：尤其在史纲与毛中特中，经常把前后只差一两年的会议、文件、政策或历史定性混进同一题里。
   - **正话反说与绝对化**：通过把“相对”改成“绝对”、把“部分/首要”改成“全部/彻底”、或把“主观动机”和“客观结果”对调来设错。
3. **刷题策略建议**：
   - 遇到没背过的当年新时政题，不要慌也不要硬猜，先用**“排错法”**（常识硬伤、跨模块硬塞、违背基本原则的表述优先排掉），往往能直接把选项缩到极小范围。
   - 对完答案后，重点把**“概念边界模糊”**和**“时间线记混”**的题归类整理，比单纯背单题答案更有用。
