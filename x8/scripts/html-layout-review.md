# 八套HTML版式复核

此前的“文字一致”和“未越界”检查，不能支撑“完全没有排版问题”的结论。本轮增加了打印组合检查、四种宽度下的离线屏幕模拟、HTML导航及脚本语法检查，并修正发现的问题。题目正文与字体族保持不变。

## 查出的问题

以提交 `0174d12c6795caf433ee8e9cef980426406deb57` 的原HTML复现，共17处打印分页问题：13道题的ABCD选项分布在两页，3处材料出处单独落到下一页，1处同一分析题的两问被拆到两页。位置如下。

| 套卷 | 选项跨页的题号 | 其他问题 |
| --- | --- | --- |
| 第1套 | 18、23 | — |
| 第2套 | 28 | — |
| 第3套 | 10、26、31 | source-attribution q38 |
| 第4套 | 4 | — |
| 第5套 | 5、26 | source-attribution q36 |
| 第6套 | 5 | — |
| 第7套 | 11 | source-attribution q35 |
| 第8套 | 21、30 | ask q37 |

`source-attribution`为材料出处孤行；`ask`为同一题两问被拆开。[原版复核记录](html-layout-baseline.json)保留了页码及位置，重跑时从Git读取原版，不覆盖当前文件。

## 修正与结果

- 打印时四个选项作为一个整体分页，避免A项在页底、BCD在下一页。
- 材料出处与前面的正文衔接，避免出处独占下一页页首。
- 同一分析题的两问保持在一起；材料正文仍可自然跨页。
- 小幅收紧打印模式的题间距、选项行间空隙及分析题间距，保持字体和主要排版比例。

八套重新导出后，上述17处问题在离线排版中全部消失。第一、二套各9页，第三至七套各10页，第八套11页，共79页。第八套末页保留完整的两问和长附注；不以删除内容或缩小字号凑固定页数。

## 检查证据

1. [当前布局结果](html-layout-audit.json)：八套打印组合检查均为0问题；320、390、768、1120像素四种宽度共32组离线屏幕模拟，未发现文字横向越界。
2. [HTML结构结果](html-structure-audit.json)：题号导航目标、唯一ID及JavaScript/内联点击处理器语法通过。语法检查不等于浏览器交互测试。
3. [正文往返检查](html-verification.json)：304题、1056个选项、40道材料分析题与Markdown一致。
4. [PDF导出检查](pdf-export.json)：全部正文片段匹配、无空白页、无文字越界。
5. 视觉查看了离线模拟的手机与桌面首页，并放大检查第三套分页、第八套材料和末页等修正位置。

## 尚未验证

本环境未完成Safari/Chrome的实际页面显示、窗口缩放、点击留白按钮与浏览器打印测试。屏幕检查使用离线排版器解析相应宽度的CSS，并按相同规则模拟选项分列；浏览器字体光栅化、控件样式和交互可能不同。因此本轮结论是“已修正可复现的17处分页问题，所列离线检查通过”，不能表述为“所有设备完全没有排版问题”。
