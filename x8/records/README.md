# 肖八刷题记录

[返回肖八总入口](../README.md)

这里保存本人真实作答、旁批与复测结果。`solutions/` 中是 AI 候选解答，不能混作本人刷题成绩，也不能直接当正式参考答案。

## 第一遍

- 第一套（原始手写卷暂未上传）：[复盘报告](round-01/x8-01/review.md) · [逐题记录](round-01/x8-01/answers.csv) · [来源与校验](round-01/x8-01/source.json)

每套单独建目录，刷过的PDF以 `x8-NN-done.pdf` 命名（例如 `x8-01-done.pdf`）；轮次以 `round-01`、`round-02` 区分。复测追加到对应报告，保留第一遍的原始选择，不用订正答案覆盖历史。尚未上传的套卷不预建空记录。

`done` 只表示该版本已刷过并保留作答痕迹，不表示全部答对、已完成订正或已通过复测。空白题卷继续保留在 `x8/pdf/`，刷过的版本保存在本目录对应轮次下。

## 使用顺序

先做题，再核验答案，最后只复测暴露出的断点。对过答案不等于掌握；至少隔一天遮住解析，能独立选对并说明关键错误项，才记为通过。没有用时记录就不推算用时，没有正式答案就不把暂定分当正式成绩。

本批先发布文字记录，`x8-01-done.pdf` 暂不上传。复盘保留首次整理的工作答案与暂定分，尚未按已上传的正式参考答案重新校准。
