### 第 1 题 · 矛盾的普遍性与特殊性相互联结｜正答 B

> **一句话主线**：高铁电制动与风力发电原理相通、经验可以跨界移植，考的是**共性寓于个性之中、特殊事物与普遍事物相互联结**。

| 选项 | 判定 | 本题为什么选 / 错在哪 | 正确说法与真实归属（换题怎么用） |
| :---: | :---: | :--- | :--- |
| **A** | ✗ 不选 | 说规律起作用的范围可以“**任意**”改变，违背规律的客观性。 | 人可以认识和利用规律、改变规律发生作用的**条件**，但不能“任意”改变规律或其范围。 |
| **B** | **✓ 选** | 高铁经验能移植到风电机组，正因为相关事物有共通规律。 | **共性寓于个性之中**，同类或相关事物包含普遍性，因此可以跨领域迁移经验。 |
| **C** | ✗ 不选 | 说间接经验比直接经验更可靠，没有依据。 | 直接经验与间接经验只是**获取途径不同**，不存在谁更可靠，都必须接受**实践检验**。 |
| **D** | ✗ 不选 | 把真理与价值统一的基础偷换成了“正确的理论”。 | 真理与价值统一的基础是**实践**，不是理论。 |

### 第 2 题 · 理论的“彻底”是指抓住事物的根本｜正答 A

> **一句话主线**：直接考马克思《〈黑格尔法哲学批判〉导言》原话——**“所谓彻底，就是抓住事物的根本。而人的根本就是人本身。”**

| 选项 | 判定 | 本题为什么选 / 错在哪 | 正确说法与真实归属（换题怎么用） |
| :---: | :---: | :--- | :--- |
| **A** | **✓ 选** | 直接对应原文对“理论彻底”的定义。 | 理论彻底 = **抓住事物的根本**（人的根本就是人本身）。 |
| **B** | ✗ 不选 | 逻辑严密不是真理或“彻底”的本质标准。 | 逻辑性属于理论的**形式要求**；真理的本质是对客观事物及其规律的正确反映。 |
| **C** | ✗ 不选 | 真理和彻底性都不看内容是不是“包罗万象”。 | 真理在于**正确反映客观规律**，不在于面面俱到、包罗万象。 |
| **D** | ✗ 不选 | 把实践的品格安到了理论头上。 | **直接现实性**是**实践**独有的品格，理论属于认识范畴，不具备直接现实性。 |

### 第 3 题 · 可变资本价值的再生产｜正答 C

> **一句话主线**：区分**不变资本（价值转移）**与**可变资本（价值由工人必要劳动再生产出来）**，别把固定资本、剩余价值和可变资本混为一谈。

| 选项 | 判定 | 本题为什么选 / 错在哪 | 正确说法与真实归属（换题怎么用） |
| :---: | :---: | :--- | :--- |
| **A** | ✗ 不选 | 说的是多次生产中逐渐转移价值，这不是可变资本。 | 属于**固定资本**（不变资本里的机器、厂房等）的价值转移方式；不变资本靠具体劳动转移价值。 |
| **B** | ✗ 不选 | 雇佣工人剩余劳动的凝结不是可变资本本身。 | 雇佣工人剩余劳动的凝结 = **剩余价值**（超过劳动力价值的那部分）。 |
| **C** | **✓ 选** | 可变资本用来买劳动力，其价值**不是转移**，而是由工人劳动再生产出来。 | 可变资本价值在生产过程中由工人的**必要劳动**重新创造（再生产）出来。 |
| **D** | ✗ 不选 | 资本家无偿占有的不是可变资本本身。 | 资本家无偿占有的是**剩余价值**（利润是其转化形式）；可变资本是付给工人的工资（劳动力价值）。 |

### 第 4 题 · 经济危机周期性的决定因素｜正答 C

> **一句话主线**：抓准因果方向——是**资本主义基本矛盾运动的阶段性**决定了经济危机的周期性，再由危机周期性导致社会资本再生产呈周期性，千万别把果当因。

| 选项 | 判定 | 本题为什么选 / 错在哪 | 正确说法与真实归属（换题怎么用） |
| :---: | :---: | :--- | :--- |
| **A** | ✗ 不选 | **因果倒置**，把结果当成了原因。 | 社会资本再生产的周期性，是经济危机周期性爆发带来的**结果**，不是决定原因。 |
| **B** | ✗ 不选 | 方向说反了，资本有机构成不是不断降低。 | 资本主义生产中，资本有机构成呈**不断提高**的一般趋势。 |
| **C** | **✓ 选** | 直接命中经济危机周期性的决定因素。 | 经济危机具有周期性，归根到底由**资本主义基本矛盾运动的阶段性**决定。 |
| **D** | ✗ 不选 | 危机可能性与货币的“价值尺度”职能无关。 | 经济危机抽象的、一般的可能性，是由货币的**流通手段**和**支付手段**职能引起的。 |

| :---: | :---: | :--- | :--- |
| **A** | ✗ 不选 | 出处不对，不是 1938 年《论新阶段》。 | “中国革命斗争的胜利要靠中国同志了解中国情况”出自 **1930 年 5 月《反对本本主义》**。 |
| **B** | ✗ 不选 | 出处不对，同样不是《论新阶段》。 | “没有调查，没有发言权”同样出自 **1930 年 5 月《反对本本主义》**。 |
| **C** | ✗ 不选 | 出处不对，时间晚了 4 年。 | “马克思列宁主义之箭，必须用了去射中国革命之的”出自 **1942 年 2 月《整顿党的作风》**。 |
| **D** | **✓ 选** | 1938 年《论新阶段》阐释马克思主义中国化的原话。 | “没有抽象的马克思主义，只有具体的马克思主义” = **1938 年六届六中全会《论新阶段》**。 |

### 第 7 题 · 中国式现代化五个特征的专属定位｜正答 A

> **一句话主线**：组合单选题，逐条核对四个特征的固定“帽子”——①②③全都戴对了，④把“鲜明特点”偷换成了“区别于西方现代化的显著标志”，排掉带④的就选 **A（①②③）**。

| 选项 | 判定 | 本题为什么选 / 错在哪 | 正确说法与真实归属（换题怎么用） |

| **A（①②③）** | **✓ 选** | ①②③三句定性全部准确，无④干扰。 | ①**人口规模巨大** = **显著特征**；②**全体人民共同富裕** = **本质特征**（也是区别于西方现代化的显著标志）；③**物质富足、精神富有** = **根本要求和崇高追求**。 |
| **B（①②④）** | ✗ 不选 | 混入了错误的 **④**。 | **④ 错在张冠李戴**：促进人与自然和谐共生是中国式现代化的“**鲜明特点**”，不是“区别于西方现代化的显著标志”。 |
| **C（①③④）** | ✗ 不选 | 同样混入了错误的 **④**，且漏掉正确的 ②。 | “区别于西方现代化的显著标志”专属 **② 全体人民共同富裕**，不能安到人与自然和谐共生上。 |
