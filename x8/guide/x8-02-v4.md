### 第 1 题｜`模型通杀`｜实刷 B ✗｜正答 C

**先听懂（评价有差异 ≠ 没对错，客体属性不因评价才存在）**
- 同一家餐厅，爱吃辣的人给五星，怕辣的人给差评——因为**评价主体的需要不同**，所以对同一客体的评价必然有差异（选 C）。
- 但“有差异”绝不等于“怎么说都对”：如果后厨卫生极差，有人硬夸它干净卫生，这就是违背客观事实的**错误评价**。
- 同时，客体有没有营养、干不干净是它本身客观具备的属性，不会因为你去评价它才突然冒出来，也不会因为你主观希望它干净它就自动变干净。

**怎么答对**
| 选项 | 关键错点 / 依据 | 判定 |
| :---: | :--- | :--- |
| A | `由人的主观愿望决定` | 唯心！客体能否满足需要由客体客观属性决定，不是想什么就有什么 → **砍** |
| B | `没有正确与错误之分` | 实刷掉坑！前半句“有科学与非科学之别”对，后半句否定正误 → **砍** |
| **C** | `主体以自身的需要作为内在尺度` | 准确解释为什么不同人评价会有差异 → **选 C** |
| D | `无法独立于人们对它的认识和评价` | 价值以主体需要为关系一端没错，但客观价值关系不以人的评价为转移 → **砍** |

**真题怎么考**
- 真题常换消费以外的场景，比如 [2023 真题第 18 题](../../papers/html/2023.html#q18)（苏轼看庐山），依然考同一模型：**主体差异能解释“仁者见仁”，但既不能否定客体的客观性，也不能推出评价没有正误。**

### 第 2 题｜`模型通杀`｜实刷 C ✗｜正答 A

**先听懂（为什么唯物史观的“最高标准”一定是生产力）**
- 把人类社会想象成一栋楼：**生产力发展**是整栋楼的物质地基（工具、技术、劳动能力与物质财富生产的总和）。地基不往上抬，制度变革、思想解放、生活改善都没有物质支撑。
- 科技只是生产力里的一个重要零部件，不能拿零部件冒充整台机器；人的觉醒属于意识层面，不能取代客观物质标准；共同富裕是社会主义的目标，不能拿来充当衡量人类一切社会形态进步的最高标准。
- *边界提醒*：“最高标准”指终极物质底盘，不等于社会进步只看产量、不管政治和文化。

**怎么答对**
| 选项 | 理论层级 | 判定 |
| :---: | :--- | :--- |
| **A 生产力发展** | 唯物史观终极物质底盘（列宁所定最高标准） | **选 A** |
| B 科学技术进步 | 生产力中的重要因素，局部不能替代整体 | **砍** |
| C 人的普遍觉醒 | 思想意识层面，不能取代客观物质标准（实刷错选） | **砍** |
| D 共同富裕 | 社会主义的本质要求与发展目标，范围不匹配 | **砍** |

**真题怎么考**
- 唯物史观里只要出现 `最高标准 / 最终决定力量 / 根本动力` 等排他性极值词，优先核对“生产力 / 生产方式 / 物质资料生产”等物质底盘，警惕用单一要素（科技）或意识状态（觉醒、观念）偷换。

### 第 3 题｜`模型通杀`｜实刷 C ✗｜正答 B

**先听懂（同一份活，换两个镜头看）**
- 你在工地搬 1 小时砖，**不是先干 1 小时具体劳动、再干 1 小时抽象劳动**，而是拿两个不同的镜头观察这**同一小时的劳动**：

| 观察镜头 | 概念 | 看什么 | 创造什么 | 反映什么关系 |
| :--- | :--- | :--- | :--- | :--- |
| **看得见的动作** | 具体劳动 | 怎么搬、用啥工具、干啥活 | 使用价值（砌好的墙） | 人与**自然**的关系（自然属性） |
| **看不见的耗费** | 抽象劳动 | 撇开具体形式，耗了多少脑力体力 | 价值（无差别人类劳动） | 人与人的**社会**关系（社会属性） |

**怎么答对**
- **砍 C**（实刷错选）：`各自独立存在的两种劳动` 把“同一劳动的两个方面”拆成了两回事，硬伤。
- **砍 A**：`空间上并存、时间上继起` 是**产业资本循环**连续进行的条件，跨章乱借。
- **砍 D**：具体劳动造使用价值、抽象劳动形成价值，两者各自都有质与量，不能乱编成“具体管质、抽象管量”。
- **选 B**：准确区分人与自然关系 vs 商品生产者的社会关系。

**真题怎么考**
- 政经真题常把“同一劳动的两个方面”偷换成“两次劳动/两种劳动”，或把“具体劳动—使用价值—自然属性”与“抽象劳动—价值—社会属性”交叉错配，抓住“同一份活、两个视角”即可通杀。

### 第 5 题｜`边界排错`｜实刷 A ✗｜正答 C

**踩坑点**
- 容易误以为“新民主主义革命”既然叫“新”，性质就变成了社会主义革命。其实它的全称是**无产阶级领导的、资产阶级民主主义革命**——性质、对象、社会主要矛盾都没变，唯一发生根本变化的是**领导阶级**。

**怎么答对**
| 比较维度 | 旧民主主义革命 | 新民主主义革命 | 变没变？ |
| :--- | :--- | :--- | :---: |
| 基本性质（A） | 资产阶级民主革命 | 资产阶级民主革命 | 没变 → **砍**（实刷错选） |
| 主要对象（B） | 帝国主义、封建主义 | 帝国主义、封建主义 | 没变 → **砍** |
| 主要矛盾（D） | 帝中矛盾、封民矛盾 | 帝中矛盾、封民矛盾 | 没变 → **砍** |
| **领导阶级（C）** | **资产阶级** | **无产阶级** | **根本标志 → 选 C** |

**真题怎么考**
- 考场把三个相邻设问切开记：**时代背景转换**看十月革命、**根本区别**看领导阶级、**开端标志**看五四运动，切勿串台。

### 第 6 题｜`边界排错`｜实刷 A ✓｜正答 A

**踩坑点**
- 史纲著作题常把不同时期的会议、文件目的混在一起。抓住题干两个限定词：`1937 年` + `对党的思想路线作了系统的哲学论证`（《实践论》《矛盾论》），立刻锁定**认识论/思想路线**层面。

**怎么答对**
- **选 A**：思想路线专治主观主义特别是**教条主义**（不看中国实际、死搬书本）。
- **砍 B**：把党的主张变为群众自觉行动，属于**群众路线**领导方法。
- **砍 C**：为七大召开创造充分条件，是 **1945 年**《关于若干历史问题的决议》。
- **砍 D**：系统说明党的政治策略问题，是 **1935 年**《论反对日本帝国主义的策略》。

**真题怎么考**
- 换著作仍考同一识别动作：如 [2025 真题第 5 题](../../papers/html/2025.html#q5)（《反对本本主义》），凡是“用现成结论代替研究实际”，都指向**反教条主义**。

### 第 8 题｜`边界排错`｜实刷 B ✗｜正答 D

**踩坑点**
- 容易把“建设军队要投入的支撑条件”（科技、人才）误当成“衡量军队建得好不好的最终检验标准”。造装备、招人才是**投入手段**，检验军队行不行最终只看**能不能打胜仗**。

**怎么答对**
- **砍 A（科技）、砍 B（人才，实刷错选）**：均为强军的重要支撑与条件，不是最终结果标准。
- **砍 C（威慑力）**：侧重影响对手行动预期，不替代人民军队建设的核心检验标准。
- **选 D（战斗力）**：国防和军队现代化的**根本指向和检验标准**始终是战斗力。

**真题怎么考**
- 单选凡问 `根本指向 / 检验标准 / 落脚点`，立刻把选项分成“投入手段”和“最终产出”两栏，手段再重要也不取代结果标准。

### 第 10 题｜`边界排错`｜实刷 B ✓｜正答 B

**踩坑点**
- 比较两本书/两个事件的“相似之处”，最容易犯的错是把**较晚、更激进一方**的主张当成双方共有。

**怎么答对**
- 拿**时间更早、阶级局限更大**的《海国图志》（地主阶级抵抗派魏源）当筛子过滤：
  - 魏源只主张“师夷长技以制夷”（学西方军事技术），**不改政治经济文化制度**（砍 A）、**不搞资产阶级思想启蒙**（砍 C）、**不发展资本主义**（砍 D，那是《资政新篇》独有）。
  - 两者交集只能退守 **B（向西方学习）**。

**真题怎么考**
- 凡遇“共同点 / 相似之处”比较题，先拿层次更低、时间更早的一方去逐项过筛，只要这一方够不到，直接排除。

### 第 11 题｜`边界排错`｜实刷 C ✗｜正答 D

**踩坑点**
- 题干是标准递进句式：`不但`（领导了伟大的辛亥革命）`……而且`（适乎世界之潮流，合乎人群之需要）——设问卡在**后半句的晚年新贡献**，实刷漏看后半句导致误选 C。

**怎么答对**
- **砍 C**（实刷错选）：推翻帝制、建立共和国 = 前半句刚说过的辛亥革命本身，重复无效。
- **砍 A、B**：以 `1911 辛亥革命` 为时间界，A（喊出“振兴中华”）和 B（与改良派论战）都在辛亥之前，早于前半句。
- **选 D**：晚年顺应时代潮流，提出**联俄、联共、扶助农工三大政策**，对三民主义作出新解释，严丝合缝对应“而且”。

**真题怎么考**
- 遇 `不但……而且……`、`不仅……更……` 类递进设问，考场先划掉“重复前半句”和“时间早于前半句”的选项，再核对后半句史实。

### 第 14 题｜`边界排错`｜实刷 B ✗｜正答 A

**踩坑点**
- 当年新文件四个选项全正确（分别对应“首要任务、抓手、支撑、保障”），容易顺手选成最具体的法规落实项 B。

**怎么答对**

**真题怎么考**
- 新文件单选四项皆正面且设问为 `首要任务 / 根本遵循 / 头等大事` 时，先按“最高指导思想 ＞ 具体法规/政策 ＞ 文化/工作保障”排层级。

### 第 17 题｜`模型通杀`｜实刷 AB ✗｜正答 AC

**先听懂（实践的直接现实性 + 实践决定认识）**
- **什么是“直接现实性”**？你在脑子里构思出一台丘陵微农机、甚至画好了图纸，它只是“观念的存在”，一亩地也耕不了；只有动手研发制造出来开进田里，才把观念变成了看得见、用得上的“现实的存在”（这就是实践独有的直接现实性）。
- **守住两条哲学底线**：
  1. **实践决定认识**，认识只能反作用于/指导实践，绝不能反过来“决定并支配”客观过程（说反就是唯心主义）。
  2. 实践有**三种基本形式**（物质生产、社会政治、科学文化），物质生产最基本，但不等于“仅限于”这一种。

**怎么答对**
| 选项 | 核心判断 | 判定 |
| :---: | :--- | :--- |
| **A** | 研发丘陵微农机，解决生产工具短缺 → 满足生产劳动资料需要 | **选 A** |
| B | `由认识决定并支配` → 颠倒实践与认识关系，唯心主义硬伤（实刷漏砍） | **砍** |
| **C** | 新技术锻造出可用新农具 → 把观念存在变为现实存在（直接现实性） | **选 C** |
| D | `仅限于生产活动这一种具体形式` → 漏掉社会政治实践、科学实验，绝对化硬伤 | **砍** |

**真题怎么考**

### 第 18 题｜`模型通杀`｜实刷 AB ✓｜正答 AB

**先听懂（系统思维 + 矛盾的同一性与斗争性）**
- 本题实刷做对，但考的都是真题超高频哲学模型，必须把底层概念踩实：
  1. **系统思维**：不是简单把各方凑在一起，而是把居民、商贩、管理部门看作一个整体，通过调整“时间和空间结构”（潮汐摊区）实现整体功能优化。
  2. **矛盾的两大属性**（必记对照表）：

| 维度 | 准确原理 | 常见挖坑变形 |
| :--- | :--- | :--- |
| **矛盾的同一性** | 相互依存、相互转化，是**有条件的、相对的** | 改成“无条件的、绝对的” |
| **矛盾的斗争性** | 相互排斥、对立，是**无条件的、绝对的** | 改成“相对的”（本题 D 项坑） |
| **事物的性质** | 由**主要矛盾的主要方面**决定 | 改成“由人的主观意志决定”（本题 C 项坑） |
| **解决矛盾的关键** | **具体问题具体分析** | 改成“发挥主观能动性是关键”（本题 C 项坑） |

**怎么答对**
- **选 A**：治理从“一刀切”改进为“潮汐摊区”，说明认识具有反复性和无限性，在实践中不断完善。
- **选 B**：兼顾三方利益、优化时空结构与治理功能，典型系统思维。
- **砍 C**：`由人的主观意志决定` 属唯心主义硬伤。
- **砍 D**：`斗争性是相对的` 直接说反（斗争性绝对、同一性相对）。*注意*：不要由 D 错就乱背成“矛盾双方绝不能融合”，本题先凭斗争性说反即可定死。

**真题怎么考**
- 系统思维常换生活/经济材料考，如 [2025 真题第 1 题](../../papers/html/2025.html#q1)（向陆地、海洋、生物资源多元化要食物，构建整体供给体系）；矛盾属性题常把“同一性相对、斗争性绝对”互换挖坑。

### 第 19 题｜`模型通杀`｜实刷 ABD ✗｜正答 AD

**先听懂（大白话数字代入法，15 秒彻底不混）**
- 设想前提：**社会**劳动生产率翻倍（同一小时内，劳动强度与复杂程度不变）。全社会技术升级后，1 小时做鸡蛋灌饼从 **10 个 → 20 个**，因为依然只耗费 1 小时劳动，这一小时新创造的总价值仍是 **100 元**：

| 指标 | 提效前（1 小时） | 提效后（1 小时） | 变没变？能不能测生产率？ |
| :--- | :---: | :---: | :--- |
| **A 单位时间商品数量** | 10 个 | **20 个** | **翻倍 → 能测（选 A）** |
| **D 单位商品耗时** | 6 分钟/个 | **3 分钟/个** | **减半 → 能测（选 D）** |
| C 单位时间耗费劳动量 | 1 小时劳动 | 1 小时劳动 | **没变 → 测不出（砍 C）** |
| B 单位时间价值总量 | 100 元（10元/个） | 100 元（5元/个） | **没变 → 测不出（砍 B，实刷坑）** |

- **防变形关键条件**：上面“价值总量不变”仅限**社会**劳动生产率变化；若是**个别**企业独自提效、仍按社会价值卖，它 1 小时能卖 20×10 = 200 元，价值总量会变大（超额剩余价值）。

**怎么答对**
- 劳动生产率 = `商品数量 ÷ 劳动时间`（A），其倒数就是 `每件商品耗时`（D）→ **选 AD**。
- 单位时间劳动耗费量（C）衡量的是劳动量不是效率，单位时间价值总量（B）在社会生产率变化时不随件数增加 → **砍 BC**。

**真题怎么考**
- 政经变形题最爱把“单位商品价值量（反比）”“同一时间价值总量（社会变则不变、个别变则变大）”“商品数量（正比）”三个量混为一谈；考场先圈定**社会还是个别**，再代入 10 个→20 个验算，零失误。

### 第 20 题｜`模型通杀`｜实刷 ABCD ✗｜正答 ACD

**先听懂（分清“钱最初谁造的” vs “钱从谁兜里转过来”）**
- 垄断资本家赚得盆满钵满，政经必须把三个不同层次的问题切开：

| 问题 | 准确答案 | 怎么理解 |
| :--- | :--- | :--- |
| **最终来源（归根到底）** | 国内外**劳动人民创造的剩余价值** | 只有活劳动才能创造新价值 |
| **分配转移途径** | 剥削本国工人、掠夺他国劳动人民、占有**非垄断企业一部分利润**、国家再分配 | 回答“钱从谁兜里转过来” |
| **主要实现方式** | 垄断组织制定的**垄断价格** | 回答“靠什么定价手段拿到手” |

- 非垄断企业的利润，最初也是它手下工人干活造出来的；垄断企业把这部分利润抢走，只是一种**分配转移途径**，绝不能说成垄断利润**归根到底**的来源。

**怎么答对**
- **选 A**：主要通过垄断价格实现（实现方式正确）。
- **选 C**：加强对其他国家劳动人民的剥削和掠夺（来源途径之一正确）。
- **选 D**：凭借垄断地位获得的超过平均利润的高额利润（定义正确）。
- **砍 B**（实刷漏砍）：把非垄断企业利润的转移写成了 `归根到底` 的来源，偷换最终来源。*避坑*：不能死背成“垄断利润不能来自非垄断企业利润”，它可以是转移途径，错在加了 `归根到底`。

**真题怎么考**
- 政经凡问利润、利息、地租、垄断利润的 `实质 / 源泉 / 归根到底来自`，答案必须落回**剩余价值 / 剩余劳动**；一旦把价格差、流通买卖或其他企业利润说成最终来源，直接排除。
