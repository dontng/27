### 第 1 题 · 价值评价的主体差异｜正答 C

> **一句话主线**：同一家餐厅，有人看口味、有人看价格、有人看服务——**评价因主体需要不同而有差异，但差异不等于没有正误，更不能靠主观愿望改变客观事实**。

| 选项 | 判定 | 本题为什么选 / 错在哪 | 正确说法与真实归属（换题怎么用） |
| :---: | :---: | :--- | :--- |
| **A** | ✗ 不选 | 错在**夸大主观愿望**：想让一家店干净，它不会自动变干净。 | **主体需要是评价的内在尺度**，但客体能否满足需要必须以**客体自身的客观性质**为根据，不能由主观愿望直接决定。 |
| **B** | ✗ 不选 | 错在**后半句否定正误**：把“评价有差异”歪曲成“评价无对错”。 | **前半句成立，须保留**（不同主体可以有各自评价根据）；但评价有**科学与非科学之别**、结果有**正误之分**（如谎报卫生情况就是错的），主体性 ≠ 任意性。 |
| **C** | **✓ 选** | **主体需要作为内在尺度**直接解释了为什么同一对象会引发不同评价。 | 评价随主体需要变化而异，但不能由此推出“怎么评都对”。 |
| **D** | ✗ 不选 | 错在**后半句主观化**：客体属性不会因为人评不评价才存在。 | 价值确实以主体需要为关系的一端（**“与主体有关”本身没错**），但**客观价值关系不以人是否认识或评价它为转移**。 |

- **易混 / 真题迁移**：[2023 真题第 18 题](../../papers/html/2023.html#q18) 把消费场景换成苏轼看庐山，同样考主体和主客体关系造成的评价差异（选 **BD**）。**自编验收**：“同一商品有人喜欢有人不喜欢，所以它没有客观属性”（✗）；“评价受主体影响，所以不存在错误评价”（✗）——两句都能讲清错在哪才算过关。

### 第 2 题 · 社会进步最高标准的定位｜正答 A

> **一句话主线**：唯物史观里，衡量社会进步的**最高标准**固定定位在**生产力发展**（提供物质基础）；推理用来帮记，不能替代固定定位。

| 选项 | 判定 | 本题为什么选 / 错在哪 | 正确说法与真实归属（换题怎么用） |
| :---: | :---: | :--- | :--- |
| **A** | **✓ 选** | **生产力发展**为社会发展提供物质基础，是本题所问的社会进步**最高标准**。 | 最高标准 ≠ **唯一维度**，不能把社会进步窄化成只剩产量，也不能据此否认政治、文化进步。 |
| **B** | ✗ 不选 | 错在**以部分代整体**：不能用生产力的某一要素替代生产力整体。 | **科学技术**是生产力的重要因素，科技进步可推动生产力，但本身不是社会进步最高标准的正式定位。 |
| **C** | ✗ 不选 | 错在**以意识代物质**：不能用主观意识状态取代客观物质标准。 | **人的觉醒**涉及意识与主体能动性，对社会发展有反作用，但不充当最高标准。 |
| **D** | ✗ 不选 | **不合题意**：张冠李戴了制度目标与唯物史观标准。 | **共同富裕**是**社会主义的本质要求与发展目标**，不是唯物史观衡量一般社会进步的最高标准。 |

### 第 3 题 · 同一劳动的两个方面｜正答 B

> **一句话主线**：（自编理解）织布这一件事，看“怎么织出布”是**具体劳动**，看“耗费了一般人类劳动”是**抽象劳动**——是**同一劳动换两个角度看**，不是先后干两份活。

| 选项 | 判定 | 本题为什么选 / 错在哪 | 正确说法与真实归属（换题怎么用） |
| :---: | :---: | :--- | :--- |
| **A** | ✗ 不选 | **移花接木**：“空间并存、时间继起”不是劳动二重性的关系。 | 劳动二重性在时空上是**统一**的；**“空间并存、时间继起”**真正归属于**产业资本循环**（不同形式、不同阶段连续运动的条件）。 |
| **B** | **✓ 选** | 准确区分了两种属性：**具体劳动**反映人与自然关系，**抽象劳动**体现商品生产者之间的社会关系。 | 记住两对绑定：**具体劳动 → 自然属性 / 使用价值**；**抽象劳动 → 社会属性 / 价值**。 |
| **C** | ✗ 不选 | 错在**把“两个方面”拆成“两种独立劳动”**：不是先干一小时具体劳动，再干一小时抽象劳动。 | 具体劳动与抽象劳动是**同一劳动过程的两个方面**，不是两次劳动或两种独立劳动。 |
| **D** | ✗ 不选 | 错在**硬拆成“质”和“量”**：不能说具体管质、抽象管量。 | 正确对应是**具体劳动创造使用价值、抽象劳动形成价值**；使用价值和价值各自都有质与量的问题。 |

### 第 4 题 · 当代资本主义最突出的特征｜正答 D

> **一句话主线**：本题问的是当代资本主义**最突出、最鲜明、最主要的特征**（固定定位：**国际金融资本的垄断**），不是问“有哪些变化”。

| 选项 | 判定 | 本题为什么选 / 错在哪 | 正确说法与真实归属（换题怎么用） |
| :---: | :---: | :--- | :--- |
| **A** | ✗ 不选 | **不合题意**：只是变化表现，不能与“最主要特征”互换。 | **产业结构调整、新经济形态出现**是当代资本主义的客观变化表现，但不是核心定性。 |
| **B** | ✗ 不选 | **不合题意**：属于社会结构变化，不是本题核心特征。 | **阶级层级复杂、多样化**是社会结构变化表现，但**不等于阶级矛盾消失**。 |
| **C** | ✗ 不选 | **不合题意**：属于国际关系行为，不是经济积累方式的核心定性。 | **霸权主义、强权政治**用来描述对外政治行为与国际关系表现。 |
| **D** | **✓ 选** | 配套解析明确将**国际金融资本的垄断**定为当代资本主义最突出、最鲜明、最主要的特征（对应资本积累向金融垄断资本积累转变）。 | **只对这一完整设问短记**，切勿泛化成“凡问当代资本主义头号问题必选金融资本”。 |

### 第 5 题 · 新旧民主主义革命的根本区别｜正答 C

> **一句话主线**：新旧民主主义革命都是反帝反封建的民主革命，性质和对象没变，**根本分水岭在于领导阶级不同**（资产阶级 vs 无产阶级）。

| 选项 | 判定 | 本题为什么选 / 错在哪 | 正确说法与真实归属（换题怎么用） |
| :---: | :---: | :--- | :--- |
| **A** | ✗ 不选 | 错在**混淆领导阶级与革命性质**：新旧两者都属于资产阶级民主主义革命范畴。 | 不能说改由无产阶级领导就已变成社会主义革命；**领导阶级**与**革命性质**是两个维度。 |
| **B** | ✗ 不选 | **不能区分**：反帝反封建的主要对象在新旧阶段没有根本改变。 | 革命对象（帝国主义、封建主义等）不是新旧民主革命的根本分界。 |
| **C** | **✓ 选** | **领导阶级**由资产阶级转为无产阶级，是区分新旧民主主义革命的**根本标志**。 | 无产阶级领导也带来不同的**发展前途**，但本题问“根本标志”，必须紧扣领导阶级。 |
| **D** | ✗ 不选 | **不能区分**：近代中国社会主要矛盾并未因新旧划分而根本改变。 | 不能用社会主要矛盾替代领导权定位。 |

- **易混 / 真题迁移**：和**第 1 套第 11 题**并读，分清三个不同设问——**时代背景转换**看**十月革命**，**根本区别**看**领导阶级**，**开端标志**看**五四运动**。

### 第 6 题 · 《实践论》《矛盾论》的针对目标｜正答 A

> **一句话主线**：1937 年延安时期的《实践论》《矛盾论》从认识论和辩证法切入，专门为了**肃清党内主观主义特别是教条主义的思想根源**。

| 选项 | 判定 | 本题为什么选 / 错在哪 | 正确说法与真实归属（换题怎么用） |
| :---: | :---: | :--- | :--- |
| **A** | **✓ 选** | “两论”系统阐明实践与认识、矛盾普遍性与特殊性的关系，直指**主观主义尤其是教条主义**的思想根源。 | 抓核心特征：**反对“用现成结论代替研究实际”**。 |
| **B** | ✗ 不选 | **不合题意**：说的是群众路线，不是思想路线著作的直接目标。 | “把党的主张化为群众自觉行动”对应**群众路线中的领导方法**。 |
| **C** | ✗ 不选 | **张冠李戴**：说的是 1945 年文件，不是 1937 年“两论”。 | “统一认识、增强团结、为七大创造条件”对应 **1945 年《关于若干历史问题的决议》**。 |
| **D** | ✗ 不选 | **张冠李戴**：时间和主题都不符。 | 系统说明抗日民族统一战线政治策略对应 **1935 年《论反对日本帝国主义的策略》**。 |

- **易混 / 真题迁移**：迁移到 [2025 真题第 5 题](../../papers/html/2025.html#q5)，“中国同志了解中国情况”同样针对教条主义（选 **B**）。两题著作不同，识别**“照搬现成结论 vs 研究中国实际”**这一共同问题比死背篇名管用得多。

| **A** | ✗ 不选 | **标签串门**：这不是守正创新的定位。 | **根本价值立场** → 对应**人民至上**（回答“为了谁”）。 |
| **B** | ✗ 不选 | **标签串门**：这不是守正创新的定位。 | **内在精神特质** → 对应**自信自立**（强调立足自身、把命运掌握在自己手中）。 |
| **C** | **✓ 选** | **鲜明理论品格**精准对应**守正创新**（处理继承与发展、变与不变的关系）。 | 靠“继承+发展”辅助记忆，但正式称谓仍须准确配对。 |

- **易混 / 真题迁移**：把配套解析另外两项一并收齐，凑足完整的**“六个必须坚持”**——**系统观念**对应**基本思想和工作方法**，**胸怀天下**对应**中国共产党人的境界格局**（这些属已有理论内容，不能一概当成“纯新时政盲区”）。

### 第 8 题 · 军队建设的检验标准 vs 投入支撑｜正答 D

> **一句话主线**：军队建得好不好，最终拿**战斗力**说话（根本指向和检验标准）；科技、人才是提高战斗力的**条件与支撑**，不能拿投入条件代替结果标准。

| 选项 | 判定 | 本题为什么选 / 错在哪 | 正确说法与真实归属（换题怎么用） |
| :---: | :---: | :--- | :--- |
| **A** | ✗ 不选 | **条件 ≠ 标准**：科技能提升战斗力，但不取代检验标准。 | **科技**提供技术条件与能力支撑；若换题专问科技地位，须按具体定位判断。 |
| **B** | ✗ 不选 | **要素 ≠ 标准**：不能把投入要素当作成效的最终标准。 | **人才**是军队建设的重要支撑；同样须在具体设问中判断其地位。 |
| **C** | ✗ 不选 | **侧重不同**：不能替代本题战斗力定位。 | **威慑力**侧重影响对方行动预期，建立在相应实力与运用之上。 |
| **D** | **✓ 选** | **战斗力**是配套解析所定的军队建设**根本指向和检验标准**，直接回答实际遂行任务能力。 | 记住**“投入条件（科技/人才）— 实际能力（战斗力）”**的层级关系。 |

### 第 11 题 · 孙中山的“不但……而且……”｜正答 D

> **一句话主线**：题干“不但”部分已经说完孙中山领导辛亥革命，“而且”问的是他**晚年更进一步的贡献**——重新解释三民主义、提出**三大革命政策**。

| 选项 | 判定 | 本题为什么选 / 错在哪 | 正确说法与真实归属（换题怎么用） |
| :---: | :---: | :--- | :--- |

### 第 19 题 · 劳动生产率衡量产品效率，不是价值总量｜正答 AD

> **一句话主线**：劳动生产率衡量的是**生产使用价值的效率**——既可用**“单位时间产多少件”**（A），也可用它的倒数**“每件耗多少时间”**（D）来算；绝不能拿价值总量或劳动耗费量来冒充。

| 选项 | 判定 | 本题为什么选 / 错在哪 | 正确说法与真实归属（换题怎么用） |
| :---: | :---: | :--- | :--- |
| **A** | **✓ 选** | **单位时间产品数量**（产品数量 ÷ 劳动时间）直接衡量生产使用价值的效率，数量越多生产率越高。 | 与**第 3 题**联动：同一劳动既产使用价值又形成价值，两种量绝不能混为一谈。 |
| **B** | ✗ 不选 | **价值总量 ≠ 产品效率**：社会生产率翻倍，同时间价值总量并不跟着翻倍。 | **条件必须带齐**：在**社会劳动生产率变化、同等时间、劳动复杂程度与强度不变**下，单位时间价值总量不变；若属**个别企业领先**（涉及超额剩余价值）或**劳动强度/复杂程度变化**，须另判。 |
| **C** | ✗ 不选 | **劳动量 ≠ 效率**：单位时间耗费多少劳动，不等于能产出多少使用价值。 | 单位时间劳动耗费衡量的是**劳动量**，与产出效率是两回事。 |
| **D** | **✓ 选** | **单位产品耗时**是效率的倒数尺度，同等条件下每件耗时越少，生产率越高。 | A 与 D 互为倒数，都指向使用价值的生产效率。 |

- **易混 / 真题迁移**：
  1. **自编数量例子**（限定社会劳动生产率提高、同样时间、劳动复杂程度与强度不变）：1 小时从做 10 件变 20 件，若该小时形成价值总量记作 100，则**单位价值从 10 降到 5**，而**每小时价值总量仍是 100**。
  2. **三量分清**（配套解析核心关系）：**单位商品价值量**与**社会必要劳动时间**成正比、与**社会劳动生产率**成反比；必须把**单位价值、同时间价值总量、产品总数量**三个量彻底分开。
  3. **自测**：产品件数翻倍，价值总量必翻倍吗？不必——先查是**社会**还是**个别企业**效率变了，再查劳动强度与复杂程度是否变了（旧版一句“单位时间价值不变”漏了这些前提，变形题容易翻车）。
