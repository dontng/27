### 第 1 题｜`可迁移排错`｜实刷 B ✓｜正答 B

- **三路对质**：**逻辑一（AI）**先读题干“高铁移植风电”配 B“普特联结”，再划 A/C/D；**逻辑二（解析）**释义共性寓于个性，逐项指谬 A/C/D；**逻辑三（张修齐）**直接不看题干，直言模拟卷分析哲学题干没用，单看选项抓 A“任意”、C“更可靠”（太草率非哲学术语）、D 偷换“二字哥哥（实践）”基础地位直接秒 B → **结论**：题干纯属障眼法，A/C/D 三项自带硬伤，纯排错即可通杀。
- **v4 汇聚动作**：① 哲学单选先扫选项不死磕材料；② 见绝对词“任意”砍 A、见非哲学术语比较“谁更可靠”砍 C；③ 见“……统一的基础”核对主语是否为“实践（二字哥哥）”，不是直接砍 D，余 B。
- **迁移接口 → 真题打法**：`绝对词“任意”` + `实践（二字哥哥）专属“基础/关键”帽子` 防偷换（真题曾把实践偷换为“正确认识/理论”；四项完整依据见 [v3](x8-03-v3.md)）。

### 第 3 题｜`排错+最小硬前提`｜实刷 C ✓｜正答 C

- **三路对质**：**逻辑一（AI）**按可变资本定义直选 C，排 A 固定资本、B/D 剩余价值；**逻辑二（解析）**区分不变资本转移与可变资本再生产；**逻辑三（张修齐）**用“蛋饼店 100w”拆解四资本概念，亮出核心排错刀：**B（剩余劳动凝结）与 D（无偿占有）同指剩余价值，单选“选 B 就得选 D”同义项直接双杀**，再以“多次逐渐转移=固定资本”砍 A，“再生产=中翻中为创造”锁 C → **结论**：张修齐的“单选同义项互杀”比背定义更锋利，配 1 条最小前提即可秒杀。

- **迁移接口 → 真题打法**：`政经三元分账（转移/再生产/剩余价值）` + `单选等价项互杀法`（两项实质同一则同时出局；四项完整依据见 [v3](x8-03-v3.md)）。
