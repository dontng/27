### 第 1 题｜`模型通杀`｜实刷 B ✓｜正答 B

- **先听懂**：高铁电制动与风力发电看似分属不同行业，中车却能直接移植高铁经验研发风电装备，核心在于二者共用同一套**电磁感应与能量转换原理**（**普遍性/共性**），只是装在高铁上叫制动、装在风车上叫发电（**特殊性/个性**）。哲学上这就是**矛盾的普遍性与特殊性相互联结**：共性寓于个性之中，抓住共通原理就能跨界迁移，再结合高海拔等具体工况做适配。
- **判定依据**：
  - **A ✗**：规律客观，人只能改变规律起作用的**条件**，不能 `任意` 改变其范围。
  - **B ✓**：跨行业技术同源与经验移植，精准体现共性与个性相互联结。
  - **C ✗**：直接经验与间接经验只是获取渠道不同，无可靠程度高低之分，均须实践检验。
  - **D ✗**：真理与价值统一的基础是**实践**，不是 `正确的理论`。
- **真题迁移**：真题常换“试点推广”“解剖麻雀”“技术嫁接”考共性与个性联结；干扰项若把“……统一的基础”主语偷换成“理论/观念”，直接判错。

### 第 2 题｜`模型通杀`｜实刷 A ✓｜正答 A

- **先听懂**：马克思说“理论只要彻底，就能说服人”。所谓“彻底”，不是文章写得滴水不漏（形式逻辑），也不是材料堆得面面俱到（包罗万象），而是**一针见血点破问题根子**——原文紧接着界定：“所谓彻底，就是抓住事物的根本。而人的根本就是人本身。”同时，必须划清理论（认识）与实践的界限：

| 范畴 | 具备的品格 | 不具备的品格（高频反坑） |
| :--- | :--- | :--- |
| **理论 / 认识** | 反映规律、指导实践、说服群众 | **没有直接现实性**（图纸不能直接变成房子） |
| **实践** | 改造客观世界，具有**直接现实性** | 不是纯主观构想，受客观规律制约 |

- **判定依据**：
  - **A ✓**：直击原文对“彻底”的界定——抓住事物的根本。
  - **B ✗ / C ✗**：`逻辑性` 仅保自洽、`包罗万象` 仅言体量，均非真理或彻底性的本质标准。
  - **D ✗**：`直接现实性` 是实践的专属品格，不能安在理论头上。
- **真题迁移**：凡选项拿 `直接现实性` 修饰理论、规划、蓝图、意识等认识范畴，一律秒排。

### 第 3 题｜`模型通杀`｜实刷 C ✓｜正答 C

- **先听懂**：按在剩余价值生产中的作用，资本分为不变资本（买生产资料）和可变资本（买劳动力）。二者的价值进入新产品的方式截然不同：生产资料是把原有价值原封不动“挪”进新产品（**转移**），而劳动力工资在购买时已被工人拿去买生活资料消费掉了，不能转移，必须靠工人在生产中重新干活挣回来（**再生产**），多干的部分则是剩余价值。

| 资本/价值形态 | 价值如何进入新产品 | 本题判定 |
| :--- | :--- | :---: |
| 不变资本（固定资本） | 在多次生产中**逐渐转移**（机器、厂房） | A ✗ |
| **可变资本（劳动力）** | 由工人必要劳动**再生产出来** | **C ✓** |
| 剩余价值 | 雇佣工人剩余劳动凝结、被资本家无偿占有 | B ✗、D ✗ |

- **判定依据**：A 指向固定资本，B、D 均指向剩余价值（单选中同指一物天然互杀），唯有 **C ✓** 准确对应可变资本的再生产方式。
- **真题迁移**：政经概念辨析盯死动词——生产资料是**转移**，劳动力是**再生产**，剩余价值是**无偿占有**。

### 第 4 题｜`模型通杀`｜实刷 A ✗｜正答 C

- **先听懂**：资本主义经济危机每隔几年周期性爆发，核心要分清**因与果**：
  1. **因（决定因素）**：资本主义基本矛盾（生产社会化 vs 生产资料私人占有）平时不断积累激化，直到商品卖不出去才以危机强制破坏产能、暂时缓解矛盾，随后复苏、再激化——这种**基本矛盾运动的阶段性**，才是危机周期性的根源。
  2. **果（连带现象）**：因为危机反复砸场子，整个社会生产被迫呈现“危机→萧条→复苏→高涨”的循环，即**社会资本再生产的周期性**。因果链为：**基本矛盾阶段性（C）→ 危机周期性 → 再生产周期性（A）**。
- **判定依据**：
  - **A ✗**：因果倒置，把危机周期性导致的**结果**当成了原因。
  - **B ✗**：资本有机构成（`c/v`）随技术进步呈**不断提高**趋势，绝非 `不断降低`（联动第 20 题）。
  - **C ✓**：准确命中决定危机周期性的底层原因。
  - **D ✗**：危机抽象可能性由货币的**流通手段**和**支付手段**引起，与标价用的 `价值尺度` 无关。
- **真题迁移**：政经遇“由……决定”设问，先排查因果倒置，再往最底层的“基本矛盾”找根源。

### 第 10 题｜`边界排错`｜实刷 C ✓｜正答 C

- **历史脉络**：1895 年甲午战败与《马关条约》签订，宣告洋务派“只学器物、不改制度”的路线破产，列强瓜分狂潮接踵而至。面对亡国灭种危机，维新派思想家严复先作《救亡决论》，继而译介赫胥黎《天演论》，用近代西方进化论敲响救亡图存的警世钟。
- **易踩坑点**：题干前半段铺垫了“民族觉醒”“救亡图存”，容易诱导选择泛泛的爱国口号（A）或改革主张（B）；必须紧盯设问限定的严复按语“进者存而传焉……负者日退，而胜者日昌”背后的**理论根据**。
- **判定依据**：
  - **C ✓**：引文直译即“进步者存留、落后者灭亡，胜者兴旺”，精准对应达尔文/赫胥黎 **`物竞天择`、`适者生存` 的社会进化论**。
  - **A ✗**：`天下兴亡，匹夫有责` 出自明末清初顾炎武，是传统爱国思想，非严复引入的西方理论。
  - **B ✗**：`中体西用` 是洋务派指导思想，恰为维新派所批判。
  - **D ✗**：`自由为体、民主为用` 是严复另一政治观点的概括，与引文“胜者日昌”的生存竞争逻辑不对应。

### 第 11 题｜`纯记`｜实刷 C ✗｜正答 A

- **历史脉络**：1921 年中共一大宣告建党时，党刚成立，虽明确了社会主义、共产主义的远大目标，但对中国当时究竟是什么性质的社会、革命分几步走尚未完全厘清。因此，建党之初最迫切的是先用马克思主义科学理论看清中国国情——紧接着 1922 年中共二大才据此分析出半殖民地半封建社会性质，制定出反帝反封建的民主革命纲领。
- **干扰项辨析与时间定位**：
  - **A ✓**：新版《史纲》原句明确界定，刚成立的中国共产党最重要的任务是 **`学习运用科学理论来观察和分析中国面对的实际问题`**（紧扣“一大建党→二大分析国情”的逻辑）。
  - **C ✗**：`到工人中去进行宣传和组织工作` 是早期党组织和建党后的重要具体实践，但属于实际工作层面，非教材界定的“最重要任务”。
  - **B ✗**：`建立最广泛的统一战线` 是大革命、抗战等后续阶段的策略任务。
  - **D ✗**：`建立完全听党指挥的武装力量` 是 1927 年大革命失败后（南昌起义、秋收起义、三湾改编）才解决的课题。

### 第 12 题｜`边界排错`｜实刷 A ✗｜正答 C

- **历史脉络**：解放战争后期，中共与民主党派的关系按三步演进：1948 年 4 月底中共发“五一口号”倡议开新政协、建联合政府，拉开协商建国序幕；1949 年 1 月，民主党派联合发表《对时局的意见》，正式公开接受中共领导；1949 年春，毛泽东进一步明确民主党派应“积极参政，共同建设新中国”，使其彻底告别旧政权下的在野党身份，转变为共同执掌和建设新中国的参政党。
- **易踩坑点**：长题干塞了两个时间点，末尾设问 **`这`** 严格就近指代紧挨着的最后一句（1949 年春“积极参政”），而非前半句或更早的“五一口号”。
- **判定依据**：
  - **A ✗ / B ✗**：`揭开协商建国序幕`、`奠定多党合作和政治协商制度基础` 均对应 **1948 年 4 月“五一口号”**。
  - **D ✗**：`公开自愿接受中共领导` 对应题干前半句 **1949 年 1 月《对时局的意见》**。
  - **C ✓**：1949 年春提出“积极参政”，标志民主党派从在野党变为参政党，即 **地位的根本变化**。

### 第 13 题｜`纯记`｜实刷 D ✓｜正答 D

- **历史脉络**：近代以来中国摆脱屈辱的三座里程碑依次递进：1945 年抗日战争胜利，首次彻底打败外敌入侵，扭转百年衰败颓势（转折点）；1949 年新中国成立，结束战乱分裂，中国人民从此站起来（结束一盘散沙）；1953 年抗美援朝胜利，刚成立的新中国打退头号强敌，向世界宣告新中国不仅站起来了，而且稳稳屹立于世界东方（立国之战宣言书）。
- **干扰项归属辨析**：
  - **A ✗ / B ✗**：`走向伟大复兴的历史转折点`（A）、`反抗外敌入侵第一次完全胜利`（B）均是 **抗日战争胜利** 的专属定性。
  - **C ✗**：`彻底结束旧中国一盘散沙局面` 是 **新民主主义革命胜利和新中国成立** 的历史意义。

- **记忆抓手**：抗战=“首次完全胜利+转折点”；建国=“站起来+结束一盘散沙”；抗美援朝=“站起来**后**屹立东方宣言书”。

- **真题迁移**：法治时政题先核对设问层级——问“法律部门”还是“具体法律/法典”，层级错位直接排除。

### 第 15 题｜`边界排错`｜实刷 D ✗｜正答 A

### 第 17 题｜`模型通杀`｜实刷 CD ✗｜正答 ABD

- **先听懂**：本题同时考查两条高频模型——**“人的本质”排雷**与**“一材多证”防漏选**。
  1. **人的本质**：吃饭睡觉等 `自然属性` 人与动物共有，无法区分不同社会中的人；真正塑造人的是家庭、职场等社会关系，故**人的本质在其现实性上是一切社会关系的总和**，本质属性是**社会属性**（绝非自然属性，也不是二者统一）。
  2. **一材多证**：材料“没有产业链和试验田，再牛的专家也使不上劲”，从三个哲学视角均成立：对**人的发挥**而言，主观能动性离不开物质条件（A）；对**生产构成**而言，试验田等劳动对象是现实生产的必要前提（B）；对**成败因素**而言，人才（内因）与配套舞台（外因）综合作用（D）。
- **判定依据**：**A ✓、B ✓、D ✓** 分别从条件、生产前提、内外因三个维度切中材料；**C ✗** 将 `自然属性` 混入人的本质界定，直接淘汰。
- **真题迁移**：马原多选常一材多证，不可因选了 D 就排斥 A、B（同类打法见 [2026 真题第 18 题](../../papers/html/2026.html#q18)）；选项将 `自然属性` 塞进“人的本质”一律判错。

### 第 18 题｜`模型通杀`｜实刷 AB ✓｜正答 AB

- **先听懂**：**价值 = 客体有用属性 + 主体实际需要**共同构成的客观关系。比如贵州刺梨本来就富含维 C（客体属性客观存在），加工成即饮原液适配上班族需求后，价值便充分实现。做题关键是把**“价值的主体性”**与**“主观唯心主义”**切开：

| 选项表述 | 判定 | 核心道理 |
| :--- | :---: | :--- |
| 直接与主体相联系（A）/ 始终以主体为中心（B） | **✓** | 符合**主体性**——没有人的需要，就不构成价值关系 |
| `本质上是主体的欲望、情感和兴趣`（C） | **✗** | 滑向**主观唯心**——抹杀了客体的客观属性（石头解不了渴） |
| `依赖于人们的认识和评价`（D） | **✗** | 违背**客观性**——青蒿素在被发现前就客观具有治疟价值 |

- **判定依据**：产地按消费者需求改进供给，正是顺应价值的主体性（**A ✓、B ✓**）；C、D 分别否定客体基础与客观存在，均错。
- **真题迁移**：遇“非遗文创”“老字号转型”等材料，凡出现 `取决于主观评价/心理感受/欲望` 一律砍掉。

### 第 19 题｜`模型通杀`｜实刷 AD ✗｜正答 ABD

- **先听懂**：资本主义生产关系不是凭空蹦出来的，而是从封建经济结构的瓦解中释放出“自由劳动力 + 货币资本”两大要素后诞生的。封建社会后期商品经济迅速扩大，旧的生产关系在**农村和城市同时变成绊脚石**：
  - 在**农村**：商品货币关系侵入，农民破产卖地，自给自足的**自然经济瓦解（A）**，大批失地农民成为自由劳动力；
  - 在**城市**：旧**行会组织**死死限制每个作坊能雇几个学徒、卖多少货、禁止跨行经营；商品市场一大，想扩大生产的手工业主必然冲破行会束缚，导致**城市行会组织瓦解（B）**，作坊升级为雇佣工人的手工工场。
  - 城乡旧壳一起碎掉，**城乡资本主义生产关系**随之产生（**D**）。
- **判定依据**：
  - **A ✓ / B ✓ / D ✓**：农村自然经济瓦解 + 城市行会瓦解（双线解体）→ 城乡资本主义生产关系产生（结果）。
  - **C ✗**：时间错位——**商人和高利贷者早在奴隶社会就已出现**，并非封建社会后期才诞生的新产物。
- **真题迁移**：政经考资本主义产生前提，牢记“农村自然经济 + 城市行会”**城乡成对瓦解**，切忌漏选城市端。

### 第 20 题｜`模型通杀`｜实刷 AB ✗｜正答 ACD

- **先听懂**：顺着老板“滚雪球式赚钱”的链条，资本积累的四项结论一次打通：
  1. **源泉**：老板把赚来的剩余价值不拿去挥霍，而是重新投进工厂扩产（剩余价值资本化）→ 资本积累是**扩大再生产的源泉（A）**。
  2. **有机构成方向**：为在竞争中胜出，老板不断用自动化机器替代人工，买机器原料的钱（`c`）占比上升、发工资的钱（`v`）占比下降 → 资本有机构成（`c/v`）呈**不断提高**趋势，绝非降低。
  3. **两大后果**：资本越积越大，财富集中于少数资本家、工人相对贫困 → **社会财富两极分化（C）**；同时机器持续替人，资本对劳动力需求相对减少 → 形成**相对过剩人口，即资本主义失业现象的根源（D）**。
- **判定依据**：**A ✓、C ✓、D ✓** 精准对应源泉与两大社会后果；**B ✗** 把有机构成变化方向彻底写反（直接联动第 4 题 B 项）。
- **真题迁移**：政经考资本积累，见 `有机构成不断降低` 或 `绝对过剩人口` 一律秒杀。

### 第 21 题｜`边界排错`｜实刷 BCD ✗｜正答 CD

- **历史脉络**：1871 年巴黎公社是无产阶级建立政权的第一次伟大尝试。公社成员担心革命胜利后，新官员像旧资产阶级官僚一样骑在人民头上，于是专门设计了“管权 + 管钱”两道防线来防止公仆变主人；但当时法国工人运动尚未形成统一的马克思主义政党领导，这恰恰成为巴黎公社仅存在 72 天即失败的重要原因之一。
- **易踩坑点**：题干设问很窄，特指防止公职人员由“公仆变主人”的**两项具体制度措施**。B 项“建立无产阶级政党”单独看政治正确，极易因忽略史实与设问边界而误选。
- **判定依据**：
  - **A ✗**：`苏维埃代表大会制度` 是 1917 年俄国十月革命后的政权形式，巴黎公社建立的是**公社委员会**。
  - **B ✗**：双重错误——历史上巴黎公社**并未**建立统一的无产阶级政党；且建党属于领导力量问题，非防官僚特权的具体制度措施。
  - **C ✓**：**管权**——全面选举制与随时撤换制，杜绝铁饭碗。
  - **D ✓**：**管钱**——取消高薪制，年薪不超熟练工人，斩断经济特权。

### 第 22 题｜`边界排错`｜实刷 BCD ✗｜正答 AC
