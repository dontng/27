## 二、四大实战排错动作（脱离题干直接用）

### 1. 多选“防全选止血”硬纪律（最快追回 +4～6 分）
- **总量控制**：整卷 17 道多选，**`ABCD` 严格控制在 3～4 题以内**（马原、史纲多选原则上先找 1 个错项砍）。
- **全选前 5 秒安检（撞线即砍，标注 `[硬伤]` / `[偏题]` / `[串台]`）**：
  1. **党内 vs 党外 / 党纪 vs 宪法**：讲`自我革命`砍`人民监督`；`总依据`属宪法不属党纪；`有机统一` ≠ `同等法律效力与适用范围`。（[1-Q26](x8-01-v4.md#q26)、[1-Q31](x8-01-v4.md#q31)、[3-Q23](x8-03-v4.md#q23)）
  2. **国内自主 vs 国际大帽子**：题干讲国内自主攻关/党建，选项突然塞入`深化国际合作/构建人类命运共同体` → 高度警惕 `[偏题]`。（[2-Q32](x8-02-v4.md#q32)、[3-Q25](x8-03-v4.md#q25)）
  3. **强硬动词 + 宾语范围 / 箭头方向**：`淘汰`只能配落后产能、不能配`传统产业`；`从 X 向 Y 转变`画反必砍；`禁止平台做大做强`、`全面转向民生`必砍。（[1-Q25](x8-01-v4.md#q25)、[2-Q26](x8-02-v4.md#q26)、[2-Q31](x8-02-v4.md#q31)、[4-Q24](x8-04-v4.md#q24)）
  4. **生造词 / 排他大帽 / 丢失限定词**：`人人民主`、`权利义务对等`、`制造业第一大产业`、`全球首个海上回收`（丢“网系”限定词）一律砍。（[2-Q23](x8-02-v4.md#q23)、[3-Q26](x8-03-v4.md#q26)、[4-Q31](x8-04-v4.md#q31)、[4-Q32](x8-04-v4.md#q32)）
  5. **新建国际组织红线**：`遵循联合国宪章` ≠ `联合国专门机构`。（[3-Q33](x8-03-v4.md#q33)）

### 2. 马原哲学：先锁设问主语 → 再砍 `[硬伤]` → 最后核 `[偏题]`
- **纠正旧版动作**：不再“不看题干直接扫选项”——先花 2 秒看清最后一句设问锁主语（防本身正确但不合题意的项混进来），再砍硬伤项。
- **高频 `[硬伤]` 词（须二步验真）**：
  - `任意` / `无条件` / `完全代替` / `独立认识主体` / `本能被动` / `互为前提`（自然与社会） / `次要矛盾起决定作用` / `形式决定内容` → 直接砍。
  - **二步验真红线**：`任何事物都在联系中`、`真理/矛盾斗争性有绝对性`均成立，**禁止见“任何/绝对”一刀切**。
- **“二三四字哥哥”专属标签**：`实践`独占统一基础/直接现实性/验真唯一标准；`生产力`是社会进步最高标准；`人民群众`是历史创造者。

### 3. 政经：4 条方向铁律 + 1 个数字代入法
1. `资本有机构成 (c/v)` 长期趋势必为**不断提高**（说“降低”直接砍）。
2. `单个资本家 + 主观动机` = **超额**；`全社会推广 + 客观结果` = **相对**。
3. **生产率代入法**：假设 1 小时 10 个（总值 100 元）→ 社会生产率翻倍变 20 个（**总值仍 100 元**、单价变 5 元）。
4. **规律不变 ≠ 作用形式不变**：生产价格/垄断**未否定**价值规律，但**改变了**作用形式；垄断**不消除**竞争。
5. **资本周转 vs 资本积累**：周转速度只看 **2 项**（周转时间 + 固流构成），其余皆属资本积累规模 `[串台]`。

### 4. 史纲：先圈年份切时间死线 + 低阶共同点筛子
- **时间死线**：圈死题干年份，晚于/早于该年的熟悉好话一律标 `[串台]` 砍掉（完整 10 条死线见 [考前抢分底牌](must-grab-cheatsheet.md#二史纲-10-条时间死线表专治-2729-题多选时间穿越)）。
- **共同点取低阶一方当筛子**：问“A 与 B 相似之处”，拿时间更早、局限更大的低阶一方（如魏源《海国图志》）逐项过滤。（[2-Q10](x8-02-v4.md#q10)）
- **长题干“这”字就近指代**：锁定紧邻“这”字的最后一句事件，不被前文长背景带偏。（[3-Q12](x8-03-v4.md#q12)）

## 四、最后 26 天的极简执行节奏

1. **刷第 5～8 套前（5 分钟）**：扫一遍 [考前抢分底牌](must-grab-cheatsheet.md) 的三张必砍表。
2. **做完核分后（10 分钟）**：只重点看错掉的多选题（尤其多勾 1 项变 0 分的题），把新踩到的坑追加进底牌；1 分冷门帽子单选扫一眼正答直接过。
3. **隔天复测（5 分钟）**：闭卷过一遍昨天多勾错项的那 4～6 道题，说出“多勾了谁 + `[硬伤/偏题/串台]` 为什么砍”，真正把 `retest_date` 填起来。
