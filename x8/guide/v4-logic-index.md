## 二、五大可迁移排错逻辑库（脱离题干直接用）

### 1. 马原哲学：先选项后题干 + 高危错标二步验真
- **动作顺序**：马原单选/多选**不先读题干**，直接扫选项；先砍硬伤，单选排 3 直接秒、多选排 2 直接反向锁剩 2 项；仅在剩 ≥2 个无硬伤项时才回头看题干配对。
- **高频硬伤标识词（须二步验真，不机械见词就杀）**：
  - `任意` / `无条件` / `完全代替` / `独立认识主体` / `本能被动` / `最可靠` / `永恒不变` → 直接定罪砍掉。
  - **二步验真红线（纠偏 v1/v2）**：`任何事物都在联系中`、`真理/矛盾斗争性有绝对性`均成立，**禁止无脑见“任何/绝对”就砍**。
- **反唯心铁律**：凡把`规律/真理/价值`说成“依赖人的主观认识/评价/欲望”或“感知之后才形成” → 直接砍。
- **“二三四字哥哥”专属标签（防偷换）**：
  - **二字哥哥 = `实践`**：独占`统一的基础`（客观规律与主观能动性、真理与价值）、`直接现实性`、`检验真理唯一标准`。把`实践`偷换成`理论/认识` → 直接砍。
  - **三字哥哥 = `生产力`** / **四字哥哥 = `人民群众`**：出现`决定力量/根本动力/历史创造者`等极值帽子时，非对应哥哥直接砍。

### 2. 政经：固定方向铁律 + 最小单向配对 + 同义互杀
- **4 条方向/概念铁律（背完直接做排错）**：
  1. `资本有机构成 (c/v)` 长期趋势必为**不断提高**（凡说“不断降低”直接砍）。
  2. `单个资本家 + 主观动机` = **超额**剩余价值；`全社会推广 + 客观结果` = **相对**剩余价值。
  3. `生产率代入法`：假设原本 1 小时 1 件（值 10 元）→ 效率翻倍变成 1 小时 2 件（总量仍 10 元、单件变 5 元），秒判单位价值量与总价值量。
  4. `规律不变 ≠ 作用形式不变`：垄断/国家干预**未否定**价值规律，但**改变了**它的作用形式（价格围绕垄断价格波动）。
- **因果单向链**：`资本主义基本矛盾运动的阶段性` → 决定 `经济危机周期性` → 导致 `社会资本再生产周期性`（倒果为因直接砍）。
- **单选等价项双杀**：单选中若两项指向同一核心概念（如 [3-Q3](x8-03-v4.md#q3) 的 B 与 D 同指“剩余价值”），两项同时排除。
- **覆盖题号**：[1-Q3](x8-01-v4.md#q3)、[1-Q4](x8-01-v4.md#q4)、[1-Q19](x8-01-v4.md#q19)、[1-Q20](x8-01-v4.md#q20)、[2-Q3](x8-02-v4.md#q3)、[2-Q19](x8-02-v4.md#q19)、[2-Q20](x8-02-v4.md#q20)、[3-Q3](x8-03-v4.md#q3)、[3-Q4](x8-03-v4.md#q4)、[3-Q20](x8-03-v4.md#q20)

### 3. 多选“全选前 5 秒安检”：边界越界一刀切（追回失分最快）
多选题当你准备全选 ABCD 或三选时，**强制停 5 秒过以下 5 道红线**，撞线直接砍：
1. **党内 vs 党外 / 党纪 vs 宪法**：讲`党的自我革命`（刀刃向内）踢掉`人民群众监督`（外部）；`总依据`属宪法不属党纪；`依法治国与依规治党有机统一` ≠ `同等法律效力与适用范围`。（[1-Q26](x8-01-v4.md#q26)、[1-Q31](x8-01-v4.md#q31)、[3-Q23](x8-03-v4.md#q23)）
2. **国内自主 vs 国际大帽子**：题干讲国内自主研发/党建内部建设，选项突然塞入`扩大对外开放/深化国际合作/构建人类命运共同体` → 高度警惕跨模块硬塞。（[2-Q32](x8-02-v4.md#q32)、[3-Q25](x8-03-v4.md#q25)）
3. **动词带宾语核范围**：看到`淘汰`必须盯紧后面宾语——`淘汰落后产能`对，`淘汰传统产业`直接砍；看到`从 X 向 Y 转变`检查方向是否写反。（[1-Q24](x8-01-v4.md#q24)、[2-Q26](x8-02-v4.md#q26)、[2-Q31](x8-02-v4.md#q31)）
4. **一字生造词 / 二元割裂 / 主宾跨界**：`人人民主`违背民主阶级性必错；选项出现“把 A 和 B 割裂/对立”必错；专项总目标必落回本领域（`依法治国`总目标必落回`法治`，不跨界换`现代化国家`）。（[2-Q25](x8-02-v4.md#q25)、[3-Q26](x8-03-v4.md#q26)、[3-Q31](x8-03-v4.md#q31)）
5. **新建国际组织红线**：中国倡议新建的国际组织均为**独立政府间国际组织**，`遵循联合国宪章` ≠ `联合国专门机构`。（[3-Q33](x8-03-v4.md#q33)）

### 4. 史纲：时间死线切割 + 低阶共同点筛子 + 避开字面撞车
- **时间死线排错**：先圈题干年份，凡超出该年份的事件/提法一刀砍净（如圈死 `1952` 砍 `1957 一五完成`与`改革开放和平发展`；圈死 `1911 辛亥前` 砍 `1914 一战 / 1915 新文化`）。（[1-Q28](x8-01-v4.md#q28)、[3-Q22](x8-03-v4.md#q22)、[3-Q27](x8-03-v4.md#q27)）
- **共同点取低阶一方当筛子**：问“A 与 B 的共同点”时，盯紧**历史局限性更大的低阶一方**（如维新派/资产阶级），凡它不可能做到的事直接砍。（[2-Q10](x8-02-v4.md#q10)）
- **主客观与外部/国内切分**：分清`侵略主观目的`（灭亡瓜分）vs `客观结果`；分清`外部时代背景转换`（1917 十月革命）vs `国内革命开端`（1919 五四）。（[1-Q10](x8-01-v4.md#q10)、[1-Q11](x8-01-v4.md#q11)）
- **长题干“这”字就近指代**：题干先铺背景再用`这`字收束设问时，锁定`这`紧邻的最后一句事件，不被前文长材料带偏。（[3-Q12](x8-03-v4.md#q12)）

### 5. 单选层级压倒 & 多选保底心法
- **单选层级压倒**：设问为`首要任务 / 根本遵循`且选项中出现最高指导思想（如`习近平法治思想`）时，层级压倒具体法律/体系/文化；问具体概念时，`专属性`压倒`放之四海而皆准的通用套话`；分清`治理方向`（事前预防）与`技术手段`（科技支撑）。（[1-Q9](x8-01-v4.md#q9)、[2-Q14](x8-02-v4.md#q14)、[2-Q15](x8-02-v4.md#q15)、[3-Q14](x8-03-v4.md#q14)）
- **多选保底心法**：过完上述 5 道安检红线后，**实在说不出硬伤的正面表述不乱删**（宁全选不凭感觉瞎扣 1 项）。（[2-Q22](x8-02-v4.md#q22)、[2-Q24](x8-02-v4.md#q24)、[2-Q30](x8-02-v4.md#q30)、[2-Q33](x8-02-v4.md#q33)）

## 四、怎么拿这张总表检验“能不能迁移到真题”？

1. **刷第 4～8 套或 2024–2026 真题前**：只花 5 分钟扫一遍上面第 二 节的 5 条规则（不看长解析）。
2. **做完核分时**：不再只看总分，专门统计 **`可迁移排错` + `排错+最小硬前提`** 这两类题的命中率，看本表里的判别式在陌生新卷上到底打穿了多少题。
3. **反向迭代**：凡是本表判别式打不穿的真题，把失效原因写回对应条目（补最小硬前提，或踢进假逻辑黑名单），绝不靠“再多写一份长解析”自嗨。
