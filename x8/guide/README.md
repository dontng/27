# 肖八逐题指南：面向真题选择题得分

[返回肖八](../README.md) · [训练安排](../mc-sop.md) · [v3审核与真题对照](audit-v3.md)

肖八用于发现知识缺口、理解易混概念，并练习把知识用于不同材料。配套解析提供本卷的答案依据，guide补理解过程和适用边界；最终用陌生真题检验，不以模拟卷答案是否背熟、是否和AI同对同错作为终点。

## 当前阅读入口

- [第1套 v3（2026-11-18审核修订）](x8-01-v3.md)：33题；优先超额与相对剩余价值、价值与分配、历史节点，含对应真题和边界说明。
- [第2套 v3（2026-11-18审核修订）](x8-02-v3.md)：33题；优先评价差异、劳动二重性与生产率、来源与分配途径。

v3已原位修订，不新增v4分叉。此前v3可在git历史查看。此次完成的是文本审核和讲解改写，用户学习效果尚待闭卷与陌生题检验；答案核对不等于原扫描件逐字验收。

一次复盘先选两道重点，简单已会题简看。原文定位或清单短记，概念题补过程；“排比正面”“没发现硬伤”“出现绝对词”均不直接产生答案。不同选项可能需要不同依据，不能排除一个就把其余未知项视为正确。
