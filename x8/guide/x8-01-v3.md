### 第 1 题 · 联系的普遍性与条件性｜正答 A

> **一句话主线**：竹林、桃花、江水、鸭子凑成一幅画，考的是世界万物**普遍联系**成统一整体，但联系**不等于任意因果**，也不能**脱离条件**或靠人感知才存在。

| 选项 | 判定 | 本题为什么选 / 错在哪 | 正确说法与真实归属（换题怎么用） |
| :---: | :---: | :--- | :--- |
| **A** | **✓ 选** | 直接扣住画面各要素相互关联、构成统一整体。 | 属于**联系普遍性的整体层面**：整个世界是相互联系的统一整体。 |
| **B** | ✗ 不选 | 把一般联系缩成了**因果**一种，又错夸成“任意两物必有因果”。 | **因果**只是引起与被引起的联系，不是一切联系；普遍联系不等于任意两物都有因果。 |
| **C** | ✗ 不选 | 把客观联系说成“被人感知之后才形成”，滑向唯心主义。 | 联系是事物**本身固有**的客观存在，人只是发现和认识它，不是创造它。 |
| **D** | ✗ 不选 | 抹掉了具体联系的**条件性**。 | 具体联系是有条件的；人可**依据条件**建立新联系，但不能任意建立。 |

- **易混 / 真题迁移**：记住三层边界——**普遍有联系、具体联系有条件、联系不都等于因果**。注意 B 错不是因为出现“任何两个”（“任何事物都处在联系中”本身是对的），这是概念判断，不能靠扫绝对词排错。

### 第 2 题 · AI 作为工具，不能代替实践检验｜正答 D

> **一句话主线**：AI 靠已有数据预测农作物品种，本质是**延伸人的认识器官**的高级工具，算得再准也必须回田里做**实践检验**。

| 选项 | 判定 | 本题为什么选 / 错在哪 | 正确说法与真实归属（换题怎么用） |
| :---: | :---: | :--- | :--- |
| **A** | ✗ 不选 | 说 AI 预测能完全取代田间试验，违背实践是检验真理的唯一标准。 | AI 预测属于**认识工具的运用**，预测结果仍须**实践检验**，不能取代田间试验。 |
| **B** | ✗ 不选 | 把认识工具升级成了独立的认识主体。 | **人**才是认识主体，AI 是**认识工具**；工具再强也不改变主体资格。 |
| **C** | ✗ 不选 | 把“数据”说成世界的本原，混淆了数据与物质。 | 数据是**信息的表征**，离不开物质载体；经济上可作生产要素，哲学上**不是世界本原**。 |
| **D** | **✓ 选** | 准确说明 AI 延伸人的认识器官、改善认识方式。 | 对应**科技发展延伸认识能力**，帮助人类更高效获取和加工信息。 |

- **易混 / 真题迁移**：分清三类设问——问“AI 是什么”看**工具 vs 主体**；问“预测算不算证明”看**实践检验**；问“怎么用 AI”看**价值尺度**。对照 [2024真题第17题](../../papers/html/2024.html#q17)（同谈 AI 但转向“科技向善”，选 ABD，需懂**合规律性与合目的性统一**）；另看 [2024第26题](../../papers/html/2024.html#q26)（数据是生产要素，与本题 C 错不矛盾：经济作用 ≠ 哲学本原）。

### 第 3 题 · 超额与相对剩余价值：先讲过程｜正答 C

> **一句话主线**：单个资本家率先改进技术，图的是**自己先比别人多赚一笔**（超额剩余价值）；等全社会普及后拉低劳动力价值，才无意中形成**相对剩余价值**。

| 选项 | 判定 | 本题为什么选 / 错在哪 | 正确说法与真实归属（换题怎么用） |
| :---: | :---: | :--- | :--- |
| **A** | ✗ 不选 | 增加必要劳动时间会挤压剩余劳动时间，资本家绝不会这么干。 | 必要劳动用来补偿劳动力价值，资本家追求的是**缩短必要劳动、扩大剩余劳动**。 |
| **B** | ✗ 不选 | 技术进步一般会让机器比重上升，不符合“降低资本有机构成”。 | **资本有机构成**由技术构成决定并反映其变化的价值构成 $c:v$（不变资本:可变资本）；技术进步下**提高是一般趋势**，但非每次改动必然提高。 |
| **C** | **✓ 选** | 直接回答“单个资本家率先改进技术的主观动机”。 | **超额剩余价值** = 单位商品**个别价值低于社会价值**的差额，按社会价值卖出即可多赚。 |
| **D** | ✗ 不选 | 这是技术普及后的**社会结果**，不是单个资本家的直接目的。 | **相对剩余价值**以**工作日不变、必要劳动缩短**为条件，须靠社会生产率提高**降低生活资料及劳动力价值**实现（单个奢侈品厂提效推不出全社会必要劳动缩短，不能死背“单个/全社会”配对）。 |

- **易混 / 真题迁移**：**自编验收**——工作日 8 小时，必要劳动从 4 降到 3（剩余从 4 变 5）是**相对剩余价值**；工作日从 8 延到 9、必要劳动仍为 4 是**绝对剩余价值**。对照 [2022真题第21题](../../papers/html/2022.html#q21)（选 ABC）：本题能解释追逐剩余价值的内在动力，但该真题还考了**市场竞争**和**工人斗争**，不能把整题全归功于这一条。

### 第 4 题 · “参与制”是股权控制制度｜正答 C

> **一句话主线**：“参与制”是政经专门术语，专指金融寡头靠**持有股票层层控股**来控制经济，千万别按字面望文生义成“参与政治”。

| 选项 | 判定 | 本题为什么选 / 错在哪 | 正确说法与真实归属（换题怎么用） |
| :---: | :---: | :--- | :--- |
| **A** | ✗ 不选 | 属于政治领域控制，不是“参与制”的定义。 | 派代理人进政府或议会，叫与政府**“个人联合”**（金融寡头的政治控制方式）。 |
| **B** | ✗ 不选 | 事实本身没错，但属于政治影响，不归“参与制”。 | 通过政策咨询机构影响政府决策，同样属于**政治控制**，见“参与”二字别乱选。 |
| **C** | **✓ 选** | 精准命中“参与制”的专门定义。 | **参与制** = 金融寡头通过**持有一定数量股票**，层层控制企业（**经济领域控制**）。 |
| **D** | ✗ 不选 | 混淆了金融寡头控股与国家垄断资本主义形式。 | 国家与私人共同投资合营，属于**国家垄断资本主义**的一种形式。 |

- **易混 / 真题迁移**：A、B、D 都不是错话，只是**归属不同**——换题改问“政治控制”选 A/B，改问“国家垄断形式”选 D，切忌记成 A/B/D 永远错。

### 第 5 题 · 实事求是的含义｜正答 B

> **一句话主线**：题干引文拆解了三个词——“实际情况”就是**实事**，“固有规律性”就是**是**，“研究并引出规律”就是**求**，合起来就是**实事求是**的定义。

| 选项 | 判定 | 本题为什么选 / 错在哪 | 正确说法与真实归属（换题怎么用） |
| :---: | :---: | :--- | :--- |
| **A** | ✗ 不选 | 讲的是联系群众，没有直接解释引文里“求规律”的定义。 | 密切联系群众对应**群众路线**和工作作风。 |
| **B** | **✓ 选** | 一一对应引文对“实事”“是”“求”的界定。 | **实事**=客观事物，**是**=内部联系即规律，**求**=去研究；认识必须从实际出发（出处《改造我们的学习》，会认定义比死背篇名更抗换材料）。 |
| **C** | ✗ 不选 | 针对的是不良文风，不对应引文主题。 | 反对党八股是 1942 年整风文献，专批不良文风；别见毛泽东引文就选该篇。 |
| **D** | ✗ 不选 | 范围太大，不能替代“实事求是”的精确定义。 | 《整顿党的作风》是整风重要讲演，涵盖思想、学风、党风、文风。 |

- **易混 / 真题迁移**：联动 [2025真题第5题](../../papers/html/2025.html#q5)（选 B）：强调“中国同志要了解中国情况”，往前多走一步，由“从实际出发”识别出它所反对的正是**教条主义**。
