## 第 34 题 · 水稻突变体与辩证创新｜`必练原理`（PDF 第 63–64 页）

### （1）指出从“奇形怪状”的植株入手打造基因宝库所涉及的唯物辩证法基本范畴。
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 从“奇形怪状”的植株入手打造水稻基因宝库，主要涉及唯物辩证法的两对基本范畴： |
| **2 第一（本质与现象）** | 第一，**本质与现象**。现象是事物的外部表现，本质是内在联系；材料中科研人员不嫌弃“病歪歪”“奇形怪状”的外在形态，而是把它当成钥匙，**透过异常现象揭示背后基因的正常功能（本质）**。 |
| **3 第二（现实与可能）** | 第二，**现实与可能**。现实蕴含着未来发展的种种可能，条件具备时会转化为新的现实；材料中看似不起眼的基因蕴含着抗旱、耐盐碱等**潜能**，打造基因宝库就是在为应对未来危机储备条件、促成新品种落地。 |
| **4 第三（收尾）** | 第三，这启示我们要善于透过现象把握本质，并积极创造主客观条件，推动有利的可能转化为现实。 |

### （2）“从与众不同的视角出发”对我们增强辩证思维能力和创新思维能力有何启示？
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | “从与众不同的视角出发”对我们增强辩证思维和创新思维能力具有重要启示： |
| **2 第一（辩证思维）** | 第一，增强**辩证思维能力**，要全面、联系、发展地看问题，**在对立中把握统一**。材料中科研人员打破“高大健壮才好”的片面看法，看到了矮秆和“异类”植株在垂直农场与太空农场中的独特价值。 |
| **3 第二（创新思维）** | 第二，增强**创新思维能力**，要**立足实践、敢于打破惯常思维定势**，发挥主观能动性提出新问题，用与众不同的视角寻找科研突破口。 |
| **4 第三（收尾）** | 第三，创新不能凭空臆想，必须像团队那样年复一年扎根田间试验，在实践中不断检验和发展创新认识。 |

> **防丢分 1 句**：第（1）问见到“看似不起眼、为未来储备”，条件反射必写 **`现实与可能`**，不能只写本质与现象！

## 第 35 题 · 习近平党建思想与政治建设｜`扫骨架等肖四`（PDF 第 64 页）

| **2 第一（理论地位）** | 第一，从地位看，它是坚持**“两个结合”**推进理论创新的重大成果，是**习近平新时代中国特色社会主义思想的重要组成部分**，极大丰富和发展了马克思主义建党学说。 |
| **3 第二（核心课题）** | 第二，它系统回答了“**建设什么样的长期执政的马克思主义政党、怎样建设长期执政的马克思主义政党**”这一重大时代课题，凝结了全党实践经验与集体智慧。 |
| **4 第三（实践作用）** | 第三，从作用看，它为管党治党、兴党强党，深入推进新时代党的建设新的伟大工程提供了**根本遵循**和科学行动指南。 |

### （2）怎样深刻领会“坚持以党的政治建设为统领”是新时代党的建设的根本要求？
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 坚持以党的政治建设为统领是新时代党的建设的根本要求，必须从以下三层深刻领会： |
| **2 第一（首位定性）** | 第一，**政治属性是马克思主义政党的第一属性**，政治建设是党的根本性建设，决定党的建设方向和效果，必须摆在首位。 |
| **3 第二（统领全局）** | 第二，要坚决维护**党中央集中统一领导**，把政治要求贯穿思想、组织、作风、纪律建设和反腐败斗争全过程，确保全党方向一致、步调一致。 |
| **4 第三（收尾）** | 第三，注重从政治上建党是我们党的优良传统，也是推进党的**自我革命**、保持党团结统一和长期执政的根本保证。 |

> **防丢分 1 句**：第（1）问必写 **`两个结合`** + **`习思想重要组成部分`**；第（2）问必写 **`政治属性是第一属性`**。
