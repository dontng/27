## 第 34 题 · 经验的适用条件与认识来源｜`必练原理`（PDF 第 19 页）

### （1）运用矛盾分析方法，说明为什么“在甲地管用的经验，在乙地未必适用”。
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 运用矛盾分析方法看，“在甲地管用的经验，在乙地未必适用”，原因如下： |
| **2 第一（背核心）** | 第一，**矛盾普遍存在且具有特殊性**，不同事物、不同阶段和不同条件下的矛盾各有其特点，**矛盾特殊性决定了事物的不同性质**。 |
| **3 第二（抄材料）** | 第二，材料中一些地方跟风种植特色果木，不看具体地理环境差异、盲目照搬外地经验，结果长势收成不如人意、产品卖不出去甚至砍树，正说明具体经验具有情境依赖性。 |
| **4 第三（收尾）** | 第三，这要求我们坚持**具体问题具体分析**，先调研乙地实际条件，反对盲目照搬和“经验自信”，因地制宜找准解决本地问题的办法。 |

### （2）从实践与认识的关系角度，分析应如何看待“经验”。
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 从实践与认识的辩证关系来看，我们应辩证、科学地看待“经验”： |
| **2 第一（背核心）** | 第一，**实践是认识的来源**，人的认识包括**直接经验**（亲身实践）和**间接经验**（学习他人），二者的本源都在实践，外地成功经验值得学习借鉴。 |
| **3 第二（抄材料）** | 第二，**实践是检验认识真理性的唯一标准，且认识随实践条件变化而发展**。材料中老一辈“地里无草才勤快”的旧经验，在猕猴桃示范园“果园生草”的新实践中得到刷新。 |
| **4 第三（收尾）** | 第三，因此对既有经验和间接经验绝不能生搬硬套，必须回到**新的实践中检验、修正和发展**，避免让经验变成思想包袱。 |

> **防丢分 1 句**：第（1）问限定了矛盾分析，绝不能拿真理相对性顶替；第（2）问必写 **`直接经验与间接经验`**。

## 第 35 题 · 先进制造业与未来产业｜`高频母题`（PDF 第 20 页）

### （1）为什么要“持续做大做强先进制造业”，“加快构建以先进制造业为骨干的现代化产业体系”？
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 持续做大做强先进制造业、构建以先进制造业为骨干的现代化产业体系，具有重要意义： |
| **2 第一（背核心）** | 第一，先进制造业是现代化产业体系的**骨干**，是巩固壮大**实体经济**根基、培育发展**新质生产力**的关键支撑。 |
| **3 第二（抄材料+核心）** | 第二，坚持智能化、绿色化、融合化方向升级制造业，能够有力推动**新旧动能接续转换**、稳定宏观经济增长。 |
| **4 第三（收尾）** | 第三，做大做强先进制造业有利于增强**自主创新能力**、提升产业链供应链自主可控水平，应对激烈国际竞争，为推进中国式现代化提供有力支撑。 |

### （2）“推动我国未来产业发展不断取得新突破”有何重大意义？
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 未来产业具有**前瞻性、战略性、颠覆性**，推动我国未来产业不断取得新突破意义重大： |
| **2 第一（核心）** | 第一，新一轮科技革命和产业变革加速演进，前瞻布局未来产业有利于**抢占未来科技和产业竞争制高点**，牢牢掌握发展主动权。 |
| **3 第二（核心）** | 第二，前沿技术不断涌现并引领未来产业崛起，有利于持续培育**新质生产力**、推动现代化产业体系迭代升级。 |
| **4 第三（收尾）** | 第三，未来产业能够创造全新优质供给与消费场景，**改善人民生活品质、促进人的全面发展**，为强国建设和民族复兴伟业注入持久动能。 |

> **防丢分 1 句**：第（2）问问的是“重大意义”，别漏最后一条 **`改善民生、促进人的全面发展`**。

### （2）如何理解“中国共产党的成就和贡献，不仅是历史性的，也是世界性的”？
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 中国共产党的百年奋斗成就和贡献，既深刻改变了中国，也深刻影响了世界： |
| **2 第一（历史性）** | 第一，从**历史性**看，党团结带领人民完成救国、兴国、富国到强国的伟大飞跃，彻底改变了中国人民和中华民族的前途命运，开辟了民族复兴正确道路。 |

## 第 38 题 · 平等有序多极化与上合组织｜`高频母题`（PDF 第 22 页）

| :--- | :--- |

| **2 第一（平等+法治）** | 第一，坚持**主权平等、相互尊重**，各国无论大小强弱一律平等，反对霸权主义；坚持**均衡有序、遵守法治**，共同恪守《联合国宪章》宗旨原则和国际法。 |
| **3 第二（多边+共赢）** | 第二，坚持**多边主义、对话协商**，通过平等沟通和平解决分歧；坚持**互利共赢、普惠包容**，反对零和博弈与阵营对抗。 |
| **4 第三（收尾）** | 第三，只有这样的多极化，才能维护国际公平正义，使全球力量格局演变有利于世界长期和平与共同发展。 |

| **2 第一（亚欧繁荣）** | 第一，以**上合力量带动亚欧繁荣**，依托高质量共建**“一带一路”**，深化经贸互联与务实合作，夯实地区共同发展基础。 |
