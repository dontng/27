## 二、考场大题 3 条保底铁律

- **分点写、首句亮词**：每小问分 3～4 点，每点第一句直接甩**加粗采分词/原理原话**，第二句用“材料中……”抄改材料，绝不写一整坨散文。
- **两问共享材料常换原理**：读完第（1）问后，第（2）问必须重新圈限定原理与主语（如[第 2 套 34 题](x8-02.md#第-34-题--经验的适用条件与认识来源)、[第 8 套 34 题](x8-08.md#第-34-题--商品价值实现与供需适配)），不能顺着第一问惯性往下写。
- **同热点跨题位看设问**：比如 AI 同时出现在[第 1 套 34 题](x8-01.md#第-34-题--ai向善与社会基本矛盾)（马原社会基本矛盾）和[38 题](x8-01.md#第-38-题--ai发展安全与全球合作)（当代国际合作四维），第一笔必须按题位定学科。
