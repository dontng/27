## 第 34 题 · 规律与能动性、问题导向｜`必练原理`（PDF 第 43 页）

### （1）结合材料，说明人们在改造世界的过程中，应该如何处理好主观能动性和客观规律性的关系。
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 改造世界必须把尊重客观规律同发挥主观能动性有机统一起来，具体做到： |
| **2 第一（尊重规律）** | 第一，**尊重客观规律是正确发挥主观能动性的前提**。规律是事物运动中固有的本质、必然联系；材料中三沙试养失败正因忽视藻类饵料规律，而昌江基地精准把握 25℃ 水温与白蝶贝滤食规律才获得成功。 |
| **3 第二（发挥能动性）** | 第二，**只有充分发挥主观能动性，才能正确认识和利用规律**。材料中人们没有被动困于核电余热排海难题，而是因地制宜设计养殖方案，变工业余热为繁育沃土，实现生态与产业双赢。 |
| **4 第三（收尾）** | 第三，**实践是二者统一的基础**，在改造世界过程中必须从客观实际出发，按规律办事、科学创新，重构人与自然和谐相处新逻辑。 |

### （2）“问题不会凭空消失，敢于直面矛盾，勇于解决难题，才能觅得新机”对我们增强问题意识、坚持问题导向有何启示？
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 这句话启示我们在工作中必须增强问题意识、坚持问题导向，做到以下三点： |
| **2 第一（理论起句）** | 第一，**问题是事物矛盾的表现形式**，矛盾具有**普遍性和客观性**。问题不会凭空消失，我们必须承认矛盾、敢于正视核电余热与生态安全等现实难题，绝不回避掩盖。 |
| **3 第二（抄材料分析）** | 第二，要深入**调查和分析问题**，材料中科研人员剖析三沙试养教训、找准昌江海域水温与浮游生物禀赋，精准把握了主要矛盾与破题抓手。 |
| **4 第三（收尾）** | 第三，要善于运用**辩证思维和创新思维**化解矛盾，通过实践探索把发展痛点转化为产业新机，推动事业不断前进。 |

> **防丢分 1 句**：第（2）问第一条必写 **`问题是矛盾的表现形式`**，否则容易丢掉哲学原理分。

## 第 35 题 · 基础研究与科技产业融合｜`高频母题`（PDF 第 43 页）

### （1）结合我国发展的内外部环境变化，说明加强基础研究的重大意义。
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 基础研究是整个科学体系的源头、所有技术问题的总机关，结合当前内外部环境，加强基础研究意义重大： |
| **2 第一（国内支撑）** | 第一，从国内看，加强基础研究是实现**高水平科技自立自强**、建成世界科技强国、推动高质量发展的迫切要求，有助于补齐我国基础研究差距。 |
| **3 第二（抢抓机遇）** | 第二，当前新一轮科技革命和产业变革加速突破，加强基础研究有利于产出**原创性颠覆性创新**，抢占未来产业和前沿科技制高点。 |
| **4 第三（外部破局）** | 第三，从外部看，全球科技竞争向基础前沿领域前移，只有夯实基础研究，才能**从源头和底层解决关键核心技术“卡脖子”问题**，掌握发展主动权。 |

### （2）如何理解推动科技创新和产业创新深度融合是“以高水平科技自立自强引领发展新质生产力的关键”？
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 推动科技创新和产业创新深度融合，是科技自立自强引领新质生产力的关键，原因如下： |
| **2 第一（科技出供给）** | 第一，**科技创新**能够催生**新产业、新模式、新动能**。材料中支持高校、科研院所对接企业攻关，正是以高质量科技供给赋能产业创新。 |
| **3 第二（产业出场景）** | 第二，**产业创新**为科技创新提供真实需求、试验场景与转化通道。强化企业创新主体地位，以高端化、绿色化、智能化产业需求牵引科研攻关，才能把科技成果转化为现实生产力。 |
| **4 第三（落地结果）** | 第三，二者深度融合既能推动传统产业转型升级，又能培育壮大新兴产业和未来产业，加快建设**现代化产业体系**，推动新旧动能转换和高质量发展。 |

> **防丢分 1 句**：第（1）问必须拆出**国内 + 外部**两头；第（2）问别漏**传统升级 + 新兴/未来成长**的产业结果。

## 第 36 题 · 辛亥革命的功绩与局限、民族复兴｜`扫骨架等肖四`（PDF 第 44 页）

### （1）为什么说辛亥革命是“中国人民和中国先进分子为实现民族独立、人民解放进行的一次伟大而艰辛探索”？
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 辛亥革命是近代中国一次伟大而艰辛的探索，既要看到其历史功绩，也要看到其历史局限： |
| **2 第一（伟大功绩）** | 第一，说它“伟大”，是因为在民族危机深重之际，它**推翻了清朝政府、结束了延续两千多年的君主专制制度**，建立共和政体，传播民主共和观念，拉开了近代中国深刻社会变革的序幕。 |
| **3 第二（艰辛局限）** | 第二，说它“艰辛”，是因为受历史条件与资产阶级软弱性制约，它**没有改变旧中国半殖民地半封建社会性质**，没有完成反帝反封建、实现民族独立和人民解放的历史任务。 |
| **4 第三（承前启后）** | 第三，辛亥革命的挫折促使先进分子继续探寻救国道路，十月革命后马克思主义传入中国、中国共产党应运而生，最终点亮了实现民族复兴的灯塔。 |

### （2）如何理解“今天，中华民族伟大复兴势不可挡”？
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 今天，中华民族伟大复兴展现出前所未有的光明前景、势不可挡，有着四大坚实依据： |
| **2 第一（党+道路）** | 第一，有**中国共产党的坚强领导**这一根本保证，有党领导人民开辟并坚持的**中国式现代化**正确道路，百年奋斗创造了两大奇迹、奠定了坚实基础。 |
| **3 第二（人民合力）** | 第二，有**亿万中国人民团结奋斗**的磅礴伟力，党心军心民心空前凝聚。 |
| **4 第三（世界潮流）** | 第三，中华民族伟大复兴顺应和平与发展的**世界历史潮流**，中国推动**构建人类命运共同体**赢得广泛国际认同，任何力量都阻挡不了前进脚步。 |

> **防丢分 1 句**：第（1）问必须**功绩与局限并写**；第（2）问别漏第 4 点 **`顺应世界发展潮流`**。

## 第 37 题 · 平凡岗位的价值与志愿服务｜`高频母题`（PDF 第 44–45 页）

### （1）如何理解“平凡铸就伟大”？
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | “平凡铸就伟大，英雄来自人民”，这句话深刻揭示了人生价值的真谛： |
| **2 第一（评价尺度）** | 第一，人生价值包含**自我价值和社会价值**，评价人生价值的**根本尺度**是看一个人的实践活动是否符合社会发展规律、促进历史进步；在今天，尤其看是否以劳动和才智**服务国家、社会和人民**。 |
| **3 第二（抄材料）** | 第二，材料中许许多多无怨无悔、倾情奉献的无名英雄，在普通岗位上脚踏实地、尽职尽责，同样创造了实实在在的社会价值。 |
| **4 第三（收尾）** | 第三，无数普通人的平凡贡献汇聚起来，正是**人民群众创造历史**的磅礴力量，启示我们在平凡岗位上也能书写不平凡的人生。 |

### （2）为什么要鼓励青年参与志愿服务，让青春在志愿服务中闪光？
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 鼓励青年参与志愿服务、让青春在志愿服务中闪光，对社会和青年自身都具有重要意义： |
| **2 第一（定性载体）** | 第一，志愿服务是**培育和践行社会主义核心价值观**的重要载体，**奉献**是志愿服务精神的要义（奉献、友爱、互助、进步）。 |
| **3 第二（对外帮社会）** | 第二，对外而言，材料中支教团、文艺宣讲师和重大活动志愿者以“小我”点亮“大我”，切实帮助群众、提升社会文明程度与道德风尚。 |
| **4 第三（对内促成长）** | 第三，对内而言，志愿服务是青年成长成才的生动课堂，有助于青年**结合自身专业与特长**了解国情、锤炼本领、收获成就感，在服务人民中实现人生价值。 |

> **防丢分 1 句**：第（2）问必写 **`核心价值观载体`** + **`结合自身专业特长`**。

## 第 38 题 · 中美战略认知与大国相处｜`高频母题`（PDF 第 45 页）

### （1）如何理解“构建中美建设性战略稳定关系，树立正确的战略认知是必须扣好的‘第一粒纽扣’”？
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 树立正确战略认知是构建中美建设性战略稳定关系必须扣好的“第一粒纽扣”，原因如下： |
| **2 第一（根本定性）** | 第一，战略认知回答的是中美究竟是**“合作伙伴”还是“战略对手”**这一根本性问题，决定了两国关系的总方向。 |
| **3 第二（因果传导）** | 第二，第一粒纽扣扣错了，认知偏差必然导致政策偏差和战略误判；只有客观理性看待对方发展，才能稳定双边预期、避免冲突对抗。 |
| **4 第三（抄材料收尾）** | 第三，中美应坚持**相互尊重、和平共处、合作共赢**，朝着材料中确立的“合作为主、竞争有度、分歧可控、和平可期”方向努力，探索新时代大国正确相处之道。 |

### （2）为什么说“‘修昔底德陷阱’是可以跨越的”？
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 所谓“修昔底德陷阱”并非历史宿命，中美完全有条件、有能力跨越这一陷阱： |
| **2 第一（批零和谬论）** | 第一，“修昔底德陷阱”源自西方对大国力量变化的**零和博弈推论**，战争与冲突绝非历史必然；中美**合则两利、斗则俱伤**。 |
| **3 第二（共同利益）** | 第二，中美在经贸往来、应对全球性挑战及两国人民福祉方面存在广泛**共同利益**，和平共处的客观条件始终存在。 |
| **4 第三（抄材料路径）** | 第三，只要双方**相向而行**，守住不冲突、不对抗底线，坚持良性有边界竞争，完善对话与危机管控机制，就一定能跨越“修昔底德陷阱”，共同维护世界和平稳定。 |

> **防丢分 1 句**：第（1）问一上来必点 **`是伙伴还是对手`** 这六个字！
