## 第 34 题 · AI 向善与社会基本矛盾｜`必练原理`（PDF 第 9 页）

### （1）为什么要推动人工智能“向上向善”？
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 推动人工智能“向上向善”，是确保科技造福人类的必然要求，原因如下： |
| **2 第一（背核心）** | 第一，**科学技术具有双重社会效应**，它既能通过促进经济社会发展造福于人类，也可能在一定条件下给人类生存和发展带来消极后果。 |
| **3 第二（抄材料）** | 第二，材料中人工智能技术发展越快，越要精准把握监管治理尺度、及时完善防范失控措施，**首要的就是有合理的社会制度保障科技正确运用**。 |
| **4 第三（收尾）** | 第三，我们要以**开放、客观的态度**研判和防范不当应用风险，引导人工智能走向有利于人类生存和发展的方向，成为造福全人类的国际公共产品。 |

### （2）运用社会基本矛盾原理，说明为什么要“不断完善相关法律法规、政策制度、应用规范、伦理准则”。
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 不断完善相关法律法规、政策制度、应用规范、伦理准则，原因如下： |
| **2 第一（背核心）** | 第一，**生产力与生产关系、经济基础与上层建筑的矛盾是人类社会基本矛盾**。**经济基础决定上层建筑，上层建筑反作用于经济基础，上层建筑一定要适合经济基础状况**。 |
| **3 第二（抄材料）** | 第二，材料中人工智能这匹“千里马”快速发展，深刻改变经济社会发展方式，同时也带来安全、可靠、可控等方面的治理新挑战，要求上层建筑及时调整变革。 |
| **4 第三（收尾）** | 第三，因此必须不断完善相关法律法规、政策制度、应用规范、伦理准则，以适应生产力发展和巩固经济基础的要求，让人工智能既跑得快又跑得稳。 |

## 第 35 题 · 新质生产力与新发展理念｜`高频母题`（PDF 第 9 页）

| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 高质量发展对发展质量和水平提出了更高要求，必须优化经济结构、培育新动能，发展新质生产力正是其内在要求和重要着力点： |
| **2 第一（抄材料+核心）** | 第一，新质生产力坚持**创新主导**，具有高科技、高效能、高质量特征，催生**新产业、新模式、新动能**，推动技术革命性突破和产业深度转型升级，助推经济质的有效提升和量的合理增长。 |
| **3 第二（抄材料+核心）** | 第二，新质生产力以**劳动者、劳动资料、劳动对象优化组合跃升**为基本内涵，以**全要素生产率大幅提升**为核心标志，有利于加快科技强国建设、赋能现代化产业体系。 |
| **4 第三（补漏+收尾）** | 第三，**新质生产力本身就是绿色生产力**，具有绿色低碳智能特点；加快形成与之相适应的生产关系，最终有利于增进民生福祉、促进全体人民共同富裕，更好支撑高质量发展。 |

| **2 第一（背核心）** | 第一，新发展理念是在**深刻总结国内外发展经验教训、分析国内外发展大势**基础上形成的，直指我国发展中的突出矛盾和问题。 |

## 第 38 题 · AI 发展安全与全球合作｜`高频母题`（PDF 第 11 页）

### （1）如何理解“让人工智能这匹千里马既跑得快又跑得稳”？
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 让人工智能这匹千里马既跑得快又跑得稳，核心是坚持发展和安全并重： |
| **2 第一（拆“快”）** | 第一，“跑得快”就是要抓住新一轮科技革命和产业变革机遇，推进**技术创新、产业赋能与新旧动能转换**，充分释放智能技术巨大能量。 |
| **3 第二（拆“稳”）** | 第二，“跑得稳”就是要秉持**以人为本、向上向善**理念，不断完善法律法规与伦理准则，加强精准监管、防范失控，确保人工智能**安全、可靠、可控**。 |
| **4 第三（收尾）** | 第三，发展为安全提供能力支撑，安全为发展筑牢底线，只有统筹发展与安全，才能让人工智能成为促进共同繁荣的重要动力源。 |

### （2）国际社会应如何“携手构建公正合理的全球人工智能治理体系”？
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 人工智能发展不应该是某个国家的独奏，而应当是全球合作的交响，国际社会应从四个维度共同努力： |
| **2 第一（发展+安全）** | 第一，坚持**开放共赢、开源共享**，推动技术红利普惠各国；同时强化**风险管控**与规则衔接，**反对泛化国家安全概念**和科技霸凌。 |
| **3 第二（文明+治理）** | 第二，坚持**包容并蓄、尊重不同文明多样性**，促进**文明交流互鉴**；坚持**真正的多边主义**，发挥**联合国主渠道作用**，依托世界人工智能合作组织等平台协调标准。 |
| **4 第三（南方+收尾）** | 第三，重点回应**全球南方**呼声，加强能力建设合作、弥合**数智鸿沟**，携手推动构建公正合理的全球人工智能治理体系和人类命运共同体。 |

> **防丢分 1 句**：第（2）问按 **`发展 + 安全 + 文明 + 治理`** 四维写，最易漏的是**文明互鉴**！
