## 第 34 题 · 真理的绝对相对性与非理性因素｜`必练原理`（PDF 第 75 页）

### （1）从真理的绝对性和相对性辩证关系的视角看，为什么需要“对既有认识的质疑”？
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 从真理的绝对性和相对性辩证关系来看，科学进步离不开“对既有认识的质疑”，原因如下： |
| **2 第一（背核心）** | 第一，**任何具体真理都是绝对性和相对性的辩证统一**。真理具有不以人的意志为转移的客观正确内容（**绝对性**），同时又受历史条件、适用**范围和程度**的限制（**相对性**）。 |
| **3 第二（抄材料）** | 第二，正因为既有科学认识具有相对性，材料中伽利略突破亚里士多德束缚、爱因斯坦追问经典物理学边界，正是靠**质疑揭示既有真理的适用边界与局限**。 |
| **4 第三（收尾）** | 第三，对既有认识的质疑不是全盘否定，而是在承认真理已有客观成果的基础上，通过实践不断**修正、扩展和深化认识**，推动真理向更高阶段发展。 |

### （2）说明认识活动中非理性因素对科学创新有何重要意义。
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 认识活动不仅依靠理性思维，非理性因素同样对科学创新具有重要意义： |
| **2 第一（列举内容）** | 第一，非理性因素狭义指**情感、意志**，广义还包括**联想、猜测、直觉、灵感**和想象力等心理因素。 |
| **3 第二（抄材料+作用）** | 第二，非理性因素对认识起**激活、驱动和提供假设**的作用。材料中好奇心是科学的起点（提出“为什么”），想象力则在头脑中构建思想实验（如伽利略斜坡滚球、爱因斯坦追光），为科学突破开辟新路。 |
| **4 第三（严谨收尾）** | 第三，非理性因素不能替代理性认识，创新设想仍须接受**严密逻辑论证与社会实践检验**，才能转化为可靠的科学真理。 |

> **防丢分 1 句**：第（2）问结尾必须补一句 **`仍须严密逻辑与实践检验`**，避免滑向主观唯心。

| :--- | :--- |
| **1 抄题起手** | 东西部协作开展 30 年来成效显著，生动彰显了党的政治优势和社会主义制度优越性： |
| **2 第一（党的政治优势）** | 第一，彰显**党的政治优势**：体现为**党中央集中统一领导**谋划定向、强大组织系统跨地区统筹干部资源，以及坚持以人民为中心的**群众路线**。 |

## 第 38 题 · 真正多边主义与四大全球倡议｜`高频母题`（PDF 第 77 页）

### （1）为什么说“一国独霸、几方共治、集团政治不是真正的多边主义”？
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 少数国家主导国际事务是历史不公，一国独霸、几方共治、集团政治绝非真正的多边主义： |
| **2 第一（拆穿假多边）** | 第一，这类做法本质上是以**小圈子和本国私利为先**，排斥广大发展中国家参与、制造阵营对立，严重破坏国际公平正义与国际秩序。 |
| **3 第二（真多边标准）** | 第二，**真正的多边主义**要求坚持**主权平等、广泛参与、平等协商、共商共建共享**，充分发挥**联合国主渠道作用**，完善全球和区域治理机制。 |
| **4 第三（收尾）** | 第三，世界上的事应由各国商量着办，只有践行真正的多边主义，才能推动国际秩序朝着更加公正合理的方向发展。 |

### （2）如何理解“提出全球发展倡议、全球安全倡议、全球文明倡议、全球治理倡议”，就是为了“推动建设一个更加美好的世界”？
| 槽位 | 答题卡实际落笔（标粗 = 核心采分点，其余 = 抄材料/凑字） |
| :--- | :--- |
| **1 抄题起手** | 面对和平、发展、安全、治理四大赤字有增无减的现实，中国提出四大全球倡议，为建设更美好世界提供系统方案： |
| **2 第一（发展+安全）** | 第一，**全球发展倡议**直面**发展鸿沟**和发展议程滞后，推动普惠包容共享繁荣；**全球安全倡议**直面**和平赤字**和安全困境，倡导共同安全、对话协商解决争端。 |
| **3 第二（文明+治理）** | 第二，**全球文明倡议**直面**价值观对立**，倡导尊重文明多样性、促进交流互鉴；**全球治理倡议**直面**治理赤字**，推动平等参与规则制定，为前三项倡议补足机制支撑。 |
| **4 第三（收尾）** | 第三，四大全球倡议各有侧重、相互促进，共同构筑起**推动构建人类命运共同体**的坚实支柱，引领世界走向持久和平与共同繁荣。 |

> **防丢分 1 句**：第（2）问四个倡议必须各自配齐 **`应对什么赤字`**（发展鸿沟 / 和平赤字 / 文明对立 / 治理赤字）。
