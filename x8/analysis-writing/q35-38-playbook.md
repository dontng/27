# 35～38 题考场保底骨架卡（不背肖八长文，专保大题 30+ 分）

> **战略定位（剩 26 天）**：**绝不整套背诵肖八 35～38 题的 32 道长答案**（背诵主战场留给 12 月初的肖四）。
> 本页把肖八 8 套 35～38 题浓缩成 **4 张答题骨架表**——考场上哪怕遇到肖四没完全押中的偏问，按**“核心采分词 + 抄材料改写”**套进去，每题稳拿 **6～7/10 分**，加上 34 题，大题保底 **30～32 分**稳稳到手。

## 第 35 题 · 新思想（经济/科技/治理/党建）

> **8 套覆盖热点**：新质生产力与新发展理念（套1）、先进制造业与未来产业（套2）、民族团结促进法与共同体意识（套3）、基础研究与科技产业融合（套4）、统筹发展安全与社会治理（套5）、习近平党建思想与政治建设（套6）、区域协调与东西部协作（套7）、投资于物和人 + 放得活管得好（套8）。

| 高频问法 | 保底答题骨架（直接套这 3～4 点） | 必带采分词库（按主题挑着写） |
| :--- | :--- | :--- |
| **为什么 / 重大意义**（如新质生产力、基础研究、区域协调、民族立法） | 1. **定位定性**：它是推动**高质量发展** / **中国式现代化**的内在要求（或重要着力点/法治保障）。<br>2. **内部作用**：解决什么痛点（补短板、换动能、优化布局、畅通循环）。<br>3. **外部应对**：增强**科技自立自强** / 产业链自主可控，应对国际竞争与风险挑战。<br>4. **落脚民生**：最终服务于**以人民为中心**、增进民生福祉、促进**共同富裕**与人的全面发展。 | `新质生产力` `全要素生产率` `新发展理念` `有效市场与有为政府` `科技自立自强` `新安全格局保障新发展格局` `铸牢中华民族共同体意识` |
| **如何理解“A 与 B 的关系”**（如发展与安全、放得活与管得好、投资于物与投资于人） | 1. **拆 A**：A 解决什么（如发展解决动力、市场释放活力、投资于物夯实物质基础）。<br>2. **拆 B**：B 解决什么（如安全提供保障、政府规范秩序、投资于人提升人力资本）。<br>3. **合起来**：二者**相辅相成、双向支撑**，必须统筹推进，合力推动高质量发展。 | 凡双词设问，**先分写各自作用，再写互相支撑，绝不漏掉任何一边** |
| **党建 / 治理类**（如政治建设、社会治理） | 1. **根本保证**：坚持**党的全面领导** / **以党的政治建设为统领**（政治性是第一属性）。<br>2. **治理格局**：**党委领导、政府负责、社会协同、公众参与**的**共建共治共享**。<br>3. **治理方式**：坚持**系统、依法、综合、源头治理**，重心下沉基层（新时代枫桥经验）。 | `两个结合` `根本遵循` `自我革命` `共建共治共享` `法治保障` |

## 第 36 题 · 史纲（历史事件 + 史今连接）

> **8 套覆盖热点**：长征胜利（套1）、理论创新与世界影响（套2）、五年规划与制度自信（套3）、辛亥革命与民族复兴（套4）、遵义会议与两个确立（套5）、孙中山与第一次国共合作（套6）、延安作风与作风常态化（套7）、过渡时期总路线与社会主义制度确立（套8）。

| 高频问法 | 保底答题骨架（按时间因果写，绝不跑偏） | 高频避坑细节（肖八 8 套实测易漏点） |
| :--- | :--- | :--- |
| **第一问：纯历史（背景 / 原因 / 意义 / 评价）** | 1. **当时背景**：面临什么危机/错误（如近代民族危机、“左”倾教条主义）。<br>2. **关键动作**：党/历史人物做了什么（确立领导核心、提出正确纲领、制定政策）。<br>3. **历史结果**：直接扭转了什么局势 + 留下了什么精神/制度基础。<br>4. **局限（若问“艰辛/旧民主革命”）**：反帝反封建未完成、未改变半殖民地半封建社会性质。 | - **遵义会议**必须写准限定词：**事实上**确立毛泽东领导地位、**开始**确立正确路线；<br>- **过渡时期必然性**别漏**国际环境**；<br>- **制度确立意义**要从国内推到**世界社会主义意义**。 |
| **第二问：史今连接（两个确立 / 复兴势不可挡 / 制度自信 / 作风常态化）** | 1. **历史证明**：百年党史证明，**党的坚强领导核心 + 科学理论指导**是战胜一切风险的根本保证。<br>2. **现实支撑**：新时代历史性成就与变革是实践依据，中国式现代化、亿万人民合力、制度自我完善提供坚实支撑。<br>3. **面向未来**：顺应世界发展潮流，推进强国建设、民族复兴伟业。 | - 问**世界性贡献**必写：`拓展发展中国家现代化途径` + `人类文明新形态` + `人类命运共同体`；<br>- 问**作风常态化**必写：`核心是党群关系` + `顽固性、反复性`。 |

## 第 37 题 · 思法（青年担当 / 价值理想 / 道德法治）

> **8 套覆盖热点**：红色基因与长征精神（套1）、家国情怀与爱国三问（套2）、个人追求与择业（套3）、平凡铸就伟大与志愿服务（套4）、伟大奋斗精神与青春（套5）、缅怀英烈与无名有名（套6）、核心价值观与家风（套7）、网络公共秩序与依法治网（套8）。

| 高频问法 | 保底答题骨架（套上基本不丢分） | 必写课本采分词 |
| :--- | :--- | :--- |
| **第一问：为什么（价值 / 理想 / 精神 / 家风 / 公共秩序）** | 1. **教材定义**：先给一句定性（如人生价值的根本尺度是**对社会的贡献**；个人理想以**社会理想**为导向；核心价值观要**内化于心、外化于行**）。<br>2. **对个人**：提供精神支柱/价值导向，抵御错误思潮，在服务社会中实现自我价值。<br>3. **对社会/国家**：凝聚社会共识、提升道德风尚、汇聚民族复兴合力。 | `自我价值与社会价值` `个人理想融入社会理想` `爱国之心/报国之志/强国之能` `内化为精神追求、外化为自觉行为` |
| **第二问：新时代青年怎么做（万能 3 层）** | 1. **思想（立志）**：坚定理想信念、厚植家国情怀，**与历史同向、与祖国同行、与人民同在**。<br>2. **本领（勤学）**：刻苦学习、练就过硬本领，把个人意愿、专业特长与**国家社会需要**结合。<br>3. **行动（实干）**：立足平凡岗位/基层一线，**艰苦奋斗、爱岗敬业、奉献社会**，在实践中创造业绩。 | 遇到**法治+道德**题（如网络治理）：先写**依法治国与以德治国相结合**（法律约束救济 + 道德教化自律），再写平台/用户各自责任，**切忌只写工作清单不写德法关系**！ |

## 第 38 题 · 当代（中国主张 / 全球治理 / 大国关系）

> **8 套覆盖热点**：AI 全球治理（套1）、平等有序多极化与上合组织（套2）、对非零关税与全球发展倡议（套3）、中美战略认知与修昔底德陷阱（套4）、中国机遇 2.0 与反脱钩断链（套5）、中国绿色发展与国际确定性（套6）、真正多边主义与四大全球倡议（套7）、东京审判与战后和平秩序（套8）。

| 高频问法 | 保底答题骨架（4 句话打穿绝大多数当代题） | 必背高频政治套话 |
| :--- | :--- | :--- |
| **为什么（中国机遇 / 真正多边主义 / 跨越陷阱 / 战后秩序）** | 1. **国际背景**：当前单边主义、保护主义、霸权主义抬头，世界变乱交织、和平/发展/安全/治理赤字凸显。<br>2. **批判错误**：零和博弈/脱钩断链/小圈子集团政治损人不利己、割裂世界。<br>3. **中国方案**：中国坚持**共商共建共享**、**真正的多边主义**、维护以**联合国为核心**的国际体系与国际法。<br>4. **受益机制**：以自身高质量发展和高水平开放为世界提供市场/创新/绿色/公共产品红利，注入**确定性和正能量**。 | `平等有序的世界多极化` `普惠包容的经济全球化` `真正的多边主义` `构建人类命运共同体` `正确义利观（义利兼顾）` `相互尊重、和平共处、合作共赢`（中美三原则） |
| **如何推进 / 四大全球倡议** | 直接按 **4 个维度**分点展开（哪怕材料只提 2 个，4 维齐写最防漏分）：<br>1. **发展**：发展优先、普惠包容、弥合发展/数智鸿沟；<br>2. **安全**：共同安全、对话协商、管控分歧；<br>3. **文明**：尊重多样文明、交流互鉴；<br>4. **治理**：以联合国为主渠道、平等参与规则制定、壮大**全球南方**声音。 | **四大全球倡议**（直接应对四大赤字）：<br>全球**发展**倡议 + 全球**安全**倡议 + 全球**文明**倡议 + 全球**治理**倡议 |
